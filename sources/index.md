## Conventions

- Filenames: descriptive kebab-case, ideally date-prefixed where the date
  matters: `2025-03-eu-ai-act-summary.pdf`, `lex-fridman-2024-12-anthropic.txt`.
- Sources are **immutable**. If you need to correct or annotate, do it in
  the wiki, not the source file.
- One row per file. Link the **Summary** column to
  `../wiki/summaries/summary-<slug>.md`.
