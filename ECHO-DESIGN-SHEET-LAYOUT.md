## Color Placement Guide

### Background
- **Main Canvas:** Pure white (#ffffff)
- **Character Shadows:** Subtle soft shadows optional
- **No outer frame or border**

### Primary Color Distribution
- **Dark Colors (charcoal/midnight blue):** 60-70% of character fill
- **Accent Colors (cyan/magenta):** 20-30% of character elements
- **Purple/Violet:** 5-10% for special effects/auras

### Accent Color Placement Strategy
1. **Eyes:** Electric intensity with cyan or magenta accents
2. **Clothing Edges:** Electric piping on seams and angles
3. **Hair/Spikes:** Electric glow around edges
4. **Motion Lines:** Alternating cyan and magenta
5. **Aura/Effects:** Gradient from magenta to cyan
6. **Particles:** Mix of both cyan and magenta

## Quality Checklist

### Composition
- [ ] 16:9 aspect ratio maintained
- [ ] White background, no distractions
- [ ] All 11 character states clearly visible
- [ ] Professional spacing and alignment
- [ ] Clear visual hierarchy (center figure largest)

### Character Consistency
- [ ] Same character across all variations
- [ ] Consistent body proportions
- [ ] Consistent facial structure (angular, sharp)
- [ ] Consistent costume/clothing elements
- [ ] Consistent color palette application

### Details
- [ ] Bold, clean line work throughout
- [ ] Motion lines visible in action poses
- [ ] Electric auras in intense expressions
- [ ] Particle effects clearly visible
- [ ] No text or watermarks overlapping design

### Color Accuracy
- [ ] Dark colors: charcoal #1a1a2e, midnight #16213e
- [ ] Electric cyan #00d8ff visible and vibrant
- [ ] Neon magenta #ff1f5a prominent
- [ ] Purple accents #9d4edd and #2c0b4e used
- [ ] White background pure and clean

### Technical
- [ ] Minimum 1920×1080px resolution
- [ ] PNG or high-quality format
- [ ] Sharp, crisp edges (no blur)
- [ ] Consistent line weights
- [ ] Professional printing quality (300 DPI for print)
