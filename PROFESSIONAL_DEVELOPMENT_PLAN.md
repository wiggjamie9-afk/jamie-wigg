## DEVELOPMENT PHASES

### Phase 1: Design & Planning (Days 1–3)
**Per app, in parallel:**
1. Finalize feature list (what's must-have vs nice-to-have)
2. Create wireframes (UI flow, screens, buttons)
3. Define premium features (what justifies $2.99/month)
4. Create content outline (words, audio scripts, example data)

**Agents:** `/frontend-design`, UI/UX specialist per app

---

### Phase 2: Core Feature Build (Days 4–10)
**Per app:**
1. Build core screens (input, display, settings)
2. Implement localStorage data persistence
3. Add progress tracking
4. Create onboarding flow
5. Build charts/data visualization (if needed)
6. Add premium paywall detection

**Agents:** frontend-design, spec-run for parallel builds

---

### Phase 3: Content & Enhancement (Days 11–18)
**Per app:**
1. Generate audio (TTS for pronunciation, meditation scripts, etc.)
2. Write content (lessons, tips, educational materials)
3. Create sample data (so new users see what a filled-in app looks like)
4. Design micro-interactions (delightful animations)
5. Add dark/light mode support

**Agents:** audio-producer, rhythmix-copywriter, animation specialist

---

### Phase 4: Polish & Testing (Days 19–28)
**Per app:**
1. Performance optimization (ensure app is fast, no lag)
2. Mobile testing (test on real phones: iPhone, Android)
3. Bug fixes (catch edge cases)
4. Accessibility audit (can elderly users use this?)
5. A/B test onboarding (which hook converts better?)
6. Create store screenshots (showcase features)
7. Final review before build

**Agents:** QA tester, accessibility specialist
