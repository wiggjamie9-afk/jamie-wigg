# Claude Overview (April 2026)

Claude is a series of large language models developed by Anthropic, an American AI safety and research company. As of April 2026, the current flagship model is **Claude Opus 4.7**, which was released on 16 April 2026.

## Key Features & Capabilities

- **Agentic AI:** Claude has evolved from a chatbot into an agentic system capable of handling multi-step tasks across computers, files, and browsers.
- **Claude Code & Cowork:**
  - **Claude Code:** A command-line interface (CLI) tool for software engineers that can read codebases, run tests, and fix bugs autonomously.
  - **Claude Cowork:** A desktop application for non-technical users to manage files, research topics, and automate office tasks.
- **Claude Design:** A specialized tool released in April 2026 for creating visual work, interactive prototypes, and presentations.
- **Constitutional AI:** Claude is trained using a "Constitution" — a set of ethical guidelines designed to ensure it is helpful, honest, and harmless.
- **Large Context Window:** The models can process vast amounts of data (e.g., 500-page PDFs) in a single prompt.

## Current Model Lineup (April 2026)

Anthropic typically releases models in three sizes to balance speed, cost, and intelligence:

| Model Size | Latest Version | Best Used For |
|------------|----------------|---------------|
| Haiku      | 4.5            | Light tasks, near-instant responses, and high speed. |
| Sonnet     | 4.6            | The "workhorse" model; ideal for scale and enterprise workflows. |
| Opus       | 4.7            | Frontier intelligence for complex coding, reasoning, and agents. |

## Access and Subscription Plans

Claude is available through a web interface at claude.ai, mobile apps, and developer APIs.

- **Free Plan:** Limited daily access to Sonnet and Haiku models.
- **Pro ($20/mo):** Higher usage limits, priority access, and the latest Opus models.
- **Team & Enterprise:** Advanced controls for organizations, with features like SSO and custom knowledge bases.
- **Claude Max:** A premium tier (starting at $100/mo) for extremely heavy users.
