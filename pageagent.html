How it works

01

Reads the DOM as text

No screenshots or multimodal models. PageAgent serializes the live page into a text view the LLM can reason about.

02

Plans & acts in-page

It decides which element to click or type into, then performs the action directly in your browser — everything stays client-side.

03

Bring your own LLM

Point it at any OpenAI-compatible endpoint with your own key. This demo uses PageAgent's free testing LLM for evaluation.

⚠️ This page loads the PageAgent demo bundle, which uses a free testing LLM — for technical evaluation only.
