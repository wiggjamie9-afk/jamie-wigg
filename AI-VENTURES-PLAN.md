- Offer 50% discount on first project if they commit by Day 6

**Day 7:** Signed contract + first payment

**Success metric:** 1 signed contract by Day 7 = $2,500-5,000 first payment + $500/mo recurring

### Automation Blueprint (Zapier + Lovable + Custom GPT)

**Client Intake Automation:**
```
Lead fills form → Zapier checks qualification criteria → 
If qualified: Auto email + calendar link for call → 
  CRM update + Slack notification (you)
If not qualified: Auto decline + nurture sequence → 
  Re-engagement email after 60 days
```

**Recurring workflow (post-signature):**
1. **Lead Qualification Loop**
   - Incoming lead email → GPT classifier (hot/warm/cold)
   - Hot: Immediate email from you
   - Warm: Drip sequence (5 emails over 14 days)
   - Cold: Archive for 30-day re-engagement

2. **Scheduling Automation**
   - Prospect confirms call → Auto calendar invite
   - 24h before call: Auto reminder email to prospect
   - After call: Auto follow-up sequence (proposal if positive)

3. **CRM + Email Integration**
   - Every lead → HubSpot/Pipedrive contact (auto-created)
   - Call notes → Auto-logged
   - Deal status → Triggered email sequence to client

4. **Proposal Generation**
   - Client signs → Auto-generate project plan (Lovable form)
   - Payment confirmed → Auto-send onboarding docs + kick-off email
   - Week 1 complete → Auto-send progress report

**Tech stack:**
- Zapier (core automation engine)
- OpenAI API (lead classification + email drafting)
- Lovable (custom intake form + dashboard)
- HubSpot/Pipedrive free tier (CRM)
- Stripe (payment processing, auto-invoicing)
- SendGrid (email sequences)
