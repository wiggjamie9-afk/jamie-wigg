## Notes on Duplicates

Several apps exist in multiple forms (e.g. `apps/hum.html`, `apps/hum/index.html`, and root `hum-app.html`). These are: a launcher card, the installable PWA, and a root-served copy respectively. The portal links to the **PWA (subfolder) version** where one exists, falling back to the single HTML file otherwise. No duplicates were deleted during consolidation — that's a separate cleanup pass if you want it.
