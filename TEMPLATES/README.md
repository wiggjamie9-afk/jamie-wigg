# TEMPLATES

Reusable prompts, post templates, design tokens, copy patterns.

Suggested files to add over time:

- `reddit-post.md` — the structure for a typical Reddit post in your voice
- `email-cold-outreach.md` — your DM/email template
- `landing-section.md` — boilerplate for a new section on the Pulse site
- `commit-message.md` — your preferred commit-message format

Drop them in as you discover patterns worth saving.
