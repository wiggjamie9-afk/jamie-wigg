## **UNIFIED BRAND GUIDELINES (All Apps)**

### **Photography Style**
- Real humans (no stock photos that look staged)
- Natural lighting
- Authentic emotions
- Context (person using app, not just holding phone)
- Diverse representation

### **Color Psychology**
```
✓ Blue/Indigo: Trust, calm, sleep (Dreams, Recovery, Resonate)
✓ Green: Health, growth, agriculture (HerdCheck, Hum)
✓ Pink/Rose: Energy, heart, vitality (Resonate, Recovery)
✓ Amber/Gold: Warmth, achievement, value (all)
```

### **Typography Hierarchy**
```
H1 (Headline): 28-32px, Bold, Color Primary
H2 (Subheading): 20-24px, Bold, Color Secondary
H3 (Section): 16-20px, SemiBold, Color Accent
Body: 14-16px, Regular, Color Dark
Caption: 12-14px, Regular, Color Muted
```

### **Button Style (All Apps)**
```
Primary CTA:
- Background: Brand primary color
- Text: White, bold
- Padding: 12px 24px
- Border-radius: 8px
- Hover: Darker shade

Secondary CTA:
- Background: Transparent
- Border: 1px solid primary
- Text: Primary color
- Hover: Light background
```

### **Card/Container Style**
```
Background: White with subtle shadow
Border-radius: 12-16px
Padding: 16-20px
Shadow: 0 4px 12px rgba(0,0,0,0.08)
Hover: Slight elevation (0 8px 24px)
```

## **QUALITY STANDARDS (MVP Gold)**

✅ **Visual Consistency**
- Same fonts across all apps (app category permitting)
- Consistent button styles
- Uniform spacing and padding
- Color palette adherence

✅ **Copy Quality**
- No grammatical errors
- Clear value proposition
- Action-oriented language
- Scannable (headlines, bullets)

✅ **User Experience**
- Zero crashes
- Sub-2s load times
- Accessible colors (WCAG AA)
- Touch targets ≥44px
- Readable fonts (16px+ minimum)

✅ **Brand Alignment**
- Distinctive personality per app
- Consistent tone of voice
- Professional photography
- Authentic testimonials

✅ **Technical Polish**
- App icon renders correctly at all sizes
- Screenshots properly dimensioned
- Video plays in all browsers
- Links work (no 404s)
