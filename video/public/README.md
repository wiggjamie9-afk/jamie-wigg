# Static assets

Drop a music file here named `music.mp3` and the `DuckMovie` composition will
use it as the soundtrack (fades in over 1.5s, fades out over 2s).

Royalty-free sources you can pull from:

- https://pixabay.com/music/ (CC0)
- https://freemusicarchive.org/ (filter by license)
- https://incompetech.com/ (Kevin MacLeod, CC BY)
- https://www.youtube.com/audiolibrary

Any clip ≥ 60 seconds works; shorter clips will go silent for the remainder.
