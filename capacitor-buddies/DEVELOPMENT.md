# Development Guide — 50 Buddy Apps iOS Wrapper

This guide covers day-to-day development, debugging, and local testing.

## Project Organization

```
capacitor-buddies/
├── package.json              # Dependencies, scripts
├── capacitor.config.ts       # Capacitor configuration
├── tsconfig.json             # TypeScript config
│
├── src/                      # TypeScript source (not required for web-only)
│   ├── index.ts             # Capacitor initialization
│   └── app.ts               # App shell setup
│
├── www/                      # Web assets (generated by build:web)
│   └── index.html           # Landing page / entry point
│
├── ios/                      # Xcode project (generated by cap init)
│   └── App/
│       ├── App.xcodeproj    # Xcode project file
│       ├── App.xcworkspace  # Xcode workspace (contains pods)
│       └── Podfile          # iOS dependencies
│
├── scripts/
│   └── build-web.mjs        # Copy apps/ → www/
│
└── docs/
    ├── BUILD.md             # Xcode setup & building
    ├── APP-STORE-SUBMISSION.md
    ├── iOS-CAPABILITIES.md
    └── DEVELOPMENT.md       # This file
```

## Initial Setup

### 1. Install Dependencies

```bash
cd capacitor-buddies
pnpm install
```

This installs:
- `@capacitor/core` — Core framework
- `@capacitor/cli` — Command-line tool
- `@capacitor/ios` — iOS platform
- Dev dependencies: TypeScript, Vitest, etc.

### 2. Build and Sync

```bash
pnpm build
```

This runs:
1. `pnpm build:web` — Copies `/apps/` to `www/`
2. `pnpm sync` — Syncs `www/` to Xcode via `cap sync ios`

After this, `ios/App/App.xcodeproj` is ready to open.

### 3. Open in Xcode

```bash
pnpm open:ios
```

Xcode launches with the iOS project. You're now ready to build and test.

## Development Workflow

### Making Changes to Buddy Apps

If you update apps in `/apps/`:

1. **Rebuild web assets:**
   ```bash
   pnpm build:web
   ```

2. **Sync to Xcode:**
   ```bash
   pnpm sync
   ```

3. **Rebuild in Xcode:**
   - Cmd+B (Build)
   - Or Cmd+R (Build & Run)

### Making Changes to Capacitor Config

If you edit `capacitor.config.ts`:

```bash
pnpm sync
```

Then rebuild in Xcode.

### Making Changes to TypeScript Source (src/)

If you edit `src/index.ts` or `src/app.ts`:

1. The changes don't auto-compile; Capacitor uses the web assets from `www/`
2. For now, Capacitor project doesn't require TypeScript compilation
3. To use TS: follow Capacitor's build setup (add a bundler)

For this project, it's simpler to edit JavaScript directly in the www/ folder or inline in index.html.

## Running in Simulator

### Start Simulator

```bash
# From Xcode: Product → Destination → iPhone 16 Pro
# Then: Product → Run (Cmd+R)
```

Or from Terminal:

```bash
# List available simulators
xcrun simctl list devices

# Boot a simulator
xcrun simctl boot "iPhone 16 Pro"

# Then: pnpm open:ios and hit Cmd+R
```

### Debug in Simulator

1. **Console:** Xcode → Debug Area (View → Debug Area → Show)
2. **Network:** Xcode → Network tab in Debug navigator
3. **Breakpoints:** Click line number in Xcode to add breakpoints

### Common Simulator Tasks

```bash
# Kill all simulators
xcrun simctl shutdown all

# Erase a simulator
xcrun simctl erase "iPhone 16 Pro"

# Install app on simulator
xcrun simctl install "iPhone 16 Pro" ios/App/build/...

# Uninstall app
xcrun simctl uninstall "iPhone 16 Pro" au.rhythmix.buddyapps
```

## Running on Physical Device

### Prerequisites

- iPhone running iOS 14.0+
- USB-C or Lightning cable
- Apple Developer account (free or paid)

### Connect Device

1. **Plug iPhone into Mac**
2. **Trust the Mac** (tap "Trust" on iPhone)
3. **In Xcode:**
   - Product → Destination → [Your iPhone]
   - Product → Run (Cmd+R)

### First Run on Device

- App builds and installs
- On iPhone, you may see "Untrusted Developer"
- Go to **Settings → General → VPN & Device Management**
- Tap your developer certificate → **Trust**
- App is now runnable

### Debugging on Device

1. **Connect device**
2. **Xcode → Window → Devices and Simulators**
3. **Select your device → Console**
4. Run app (Cmd+R) and see logs in Xcode console

## Logs & Console Output

### From TypeScript/JavaScript

```typescript
console.log('[BuddyApps]', 'Message'); // Shows in Xcode console
console.error('[BuddyApps ERROR]', error); // Red in Xcode
```

### Viewing Logs in Xcode

1. **Product → Scheme → Edit Scheme**
2. **Run tab → Pre-actions or Post-actions**
3. Or: **View → Debug Area → Show**

### Viewing Logs from Terminal

After building, use `xcrun` to stream logs:

```bash
xcrun simctl spawn booted log stream --level debug | grep BuddyApps
```

## File Synchronization

### www/ to Xcode

When you run `pnpm sync`:

```bash
# Equivalent to:
cap sync ios

# This copies:
# www/ → ios/App/App/public/ (or similar)
# capacitor.config.ts → ios/App/capacitor.config.json
```

### Troubleshooting Sync Issues

```bash
# If sync fails, try:
rm -rf ios/App/Pods
pnpm sync

# Or reset Capacitor:
npx cap update ios
```

- [ ] Microphone access works (if app uses microphone)

## Troubleshooting

### App Won't Launch

1. **Check console:** View → Debug Area → Show
2. **Look for errors:** Search for "[BuddyApps ERROR]"
3. **Check www/ folder:** Make sure `www/index.html` exists
4. **Clean build:** Cmd+Shift+K, then Cmd+B

### Build Fails with CocoaPods Error

```bash
cd ios/App
rm -rf Pods Podfile.lock
pod install
cd ../..
pnpm sync
```

### Xcode Signing Issues

1. Go to: Signing & Capabilities
2. Enable "Automatically manage signing"
3. Select your Team
4. Xcode creates provisioning profile automatically

### White Screen on Launch

1. Check Xcode console for JS errors
2. Verify `www/index.html` exists and is valid
3. Check `capacitor.config.ts` — `webDir` should be `"www"`
4. Try clearing browser cache: Safari → Develop → Empty Web Storage

## Performance Tips

### Optimize Asset Size

- Minify CSS and JavaScript
- Compress images (use WebP format if possible)
- Remove unused CSS/JS from Buddy Apps

### Monitor Memory

- Xcode → Debug navigator → Memory gauge
- If >500MB, check for memory leaks in Buddy Apps

### Optimize Load Time

- Code-split large Buddy Apps
- Lazy-load heavy features
- Use Service Workers for caching

## Production Builds

### Archive for App Store

```bash
pnpm open:ios
# In Xcode: Product → Archive
# Xcode Organizer: Validate App, Distribute App
```

See **APP-STORE-SUBMISSION.md** for full steps.

### Version Bumping

Update version in two places:

```json
// package.json
"version": "1.0.1"

// capacitor.config.ts (CFBundleVersion in Info.plist)
```

Then:

```bash
pnpm build
pnpm open:ios
# Product → Archive
```
