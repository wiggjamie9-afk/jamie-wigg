# Quick Start — 50 Buddy Apps iOS Wrapper

Get up and running in 5 minutes.

## Prerequisites

- **Mac** with Xcode 15+
- **Node.js 20+** and **pnpm 9+**
- **Apple Developer account** (free to start, $99/year for App Store)

## Step 1: Clone & Install

```bash
git clone <repo-url> capacitor-buddies
cd capacitor-buddies
pnpm install
```

Takes ~2 minutes.

## Step 2: Build & Sync

```bash
pnpm build
```

This:
- Copies web assets from `/apps/` to `www/`
- Syncs to Xcode project

Takes ~30 seconds.

## Step 3: Open Xcode

```bash
pnpm open:ios
```

Xcode launches with the iOS project ready.

## Step 4: Run in Simulator

In Xcode:
- **Product → Destination → iPhone 16 Pro** (or any model)
- **Product → Run** (or press `Cmd+R`)

The app builds and launches in the simulator.

## Step 5: Test on Physical Device (Optional)

1. **Plug in iPhone via USB**
2. **In Xcode: Product → Destination → [Your iPhone]**
3. **Product → Run** (Cmd+R)
4. On iPhone: **Settings → General → VPN & Device Management → Trust** your developer cert
5. App launches on device

## Common Commands

```bash
pnpm build:web   # Update web assets only
pnpm sync         # Sync www/ to Xcode
pnpm build        # Both above
pnpm open:ios     # Open Xcode
pnpm test         # Run tests
```

## File Structure Quick Ref

| Folder | Purpose |
|---|---|
| `www/` | Web assets (generated by build:web) |
| `src/` | TypeScript/JavaScript source |
| `ios/App/` | Xcode iOS project |
| `scripts/` | Build scripts |
