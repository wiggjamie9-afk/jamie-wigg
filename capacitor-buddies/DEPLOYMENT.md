# CI/CD Deployment — GitHub Actions for TestFlight

This document covers automated builds and TestFlight uploads via GitHub Actions.

## Overview

The `.github/workflows/ios-build.yml` workflow automatically builds, signs, and uploads the app to TestFlight whenever you push to the `main` branch or manually trigger it.

## Prerequisites

You need to set up:

1. **Apple Developer Account** (paid, $99/year) with App ID and provisioning profiles
2. **GitHub Secrets** for signing certificates and API keys
3. **GitHub Actions** enabled on your repository

## Step 1: Generate Signing Certificates and Provisioning Profiles

Use Xcode to generate and download your signing credentials:

### On your Mac:

```bash
cd /home/user/jamie-wigg/capacitor-buddies
pnpm run open:ios
```

In Xcode:

1. **Product → Scheme → Edit Scheme**
2. **Build** tab
3. Ensure **Code Sign Identity** is set to your team
4. Go to **Xcode Preferences → Accounts**
5. Select your Apple Developer account
6. Click **Manage Certificates** → **+** (if needed)
7. Select **iOS Distribution** and **iOS Development**
8. Close and return to project

Then:

1. **Project Settings → Signing & Capabilities**
2. **Team** dropdown → select your team
3. Xcode auto-provisions with a wildcard provisioning profile

### Export Signing Credentials:

On macOS, Xcode stores certificates in Keychain. To export:

```bash
# Export the distribution certificate (as .p12)
security find-identity -v -p codesigning | grep "iPhone Distribution"

# Get the certificate name, then export it:
# security export-identity ~/distribution-cert.p12 -k [cert-name] -p [password]
```

Alternatively, use [Fastlane Match](https://docs.fastlane.tools/actions/match/) to store certificates in a private Git repo.

## Step 2: Set Up GitHub Secrets

Go to your GitHub repository **Settings → Secrets and variables → Actions**.

Add these secrets:

| Secret Name | Description | Example |
|-------------|-------------|---------|
| `APPLE_TEAM_ID` | Your Apple Team ID (10 alphanumeric) | `ABC123DEF4` |
| `APPLE_BUNDLE_ID` | Your app's bundle ID | `au.rhythmix.buddyapps` |
| `APPLE_ID` | Your Apple Developer account email | `developer@example.com` |
| `APPLE_ID_PASSWORD` | App-specific password (NOT your main Apple ID password) | `abcd-efgh-ijkl-mnop` |
| `FASTLANE_SESSION` | Fastlane session token (auto-generated) | Generated by fastlane |
| `MATCH_PASSWORD` | Encryption password for Match repo (if using Match) | `secure-password` |
| `MATCH_GIT_URL` | Private Git repo for certificates (if using Match) | `https://github.com/yourname/cert-repo.git` |

### Generate App-Specific Password:

1. Go to [Apple ID Account](https://appleid.apple.com/account/home)
2. **Sign In** with your Apple ID
3. **Security** → **App-Specific Passwords**
4. Click **Generate** → give it a name (e.g., "GitHub Actions")
5. Copy the generated password and add it to GitHub as `APPLE_ID_PASSWORD`

## Step 3: Configure Fastlane (Recommended)

Fastlane simplifies certificate management and TestFlight uploads.

```bash
cd /home/user/jamie-wigg/capacitor-buddies
sudo gem install fastlane -NV  # or: brew install fastlane

fastlane init ios
# Choose: "y" for enterprise, or "n" then select match/testflight
```

This creates `fastlane/Fastfile`. Edit it:

```ruby
default_platform(:ios)

platform :ios do
  desc "Build and upload to TestFlight"
  lane :beta do
    build_app(
      workspace: "ios/App/App.xcworkspace",
      scheme: "App",
      configuration: "Release",
      destination: "generic/platform=iOS",
      archive_path: "ios/build/App.xcarchive",
      export_method: "app-store",
      export_options: {
        teamID: ENV["APPLE_TEAM_ID"],
        signingStyle: "automatic"
      },
      skip_package_ipa: true,
      skip_package_pkg: true
    )
    
    upload_to_testflight(
      api_key_path: "fastlane/api_key.json",
      skip_waiting_for_build_processing: true,
      skip_submission: true,
      app_identifier: ENV["APPLE_BUNDLE_ID"]
    )
  end
end
```

Generate an API key (for TestFlight uploads):

1. Go to [App Store Connect](https://appstoreconnect.apple.com)
2. **Users and Access** → **Keys**
3. Click **+** to create a new key
4. Name: "GitHub Actions"
5. Access: select "Admin" or minimal required roles
6. Click **Generate**
7. Download the `.p8` file
8. Base64 encode it:
   ```bash
   cat ~/Downloads/AuthKey_KEYID.p8 | base64 | pbcopy
   ```
9. Add to GitHub Secrets as `APPSTORE_CONNECT_API_KEY_BASE64`

## Step 4: Create GitHub Actions Workflow

Create `.github/workflows/ios-build.yml`:

```yaml
name: iOS Build & TestFlight

on:
  push:
    branches: [main]
    paths:
      - 'capacitor-buddies/**'
      - 'apps/**'
      - '.github/workflows/ios-build.yml'
  workflow_dispatch:

jobs:
  build:
    runs-on: macos-latest
    steps:
      - uses: actions/checkout@v4

      - name: Install Node.js
        uses: actions/setup-node@v4
        with:
          node-version: '20'

      - name: Install pnpm
        run: npm install -g pnpm@9

      - name: Install dependencies
        working-directory: ./capacitor-buddies
        run: pnpm install

      - name: Build web assets
        working-directory: ./capacitor-buddies
        run: pnpm run build:web

      - name: Sync to iOS
        working-directory: ./capacitor-buddies
        run: pnpm run sync

      - name: Build iOS Archive
        working-directory: ./capacitor-buddies/ios/App
        run: |
          xcodebuild -workspace App.xcworkspace \
            -scheme App \
            -configuration Release \
            -derivedDataPath DerivedData \
            -archivePath DerivedData/App.xcarchive \
            archive \
            CODE_SIGN_IDENTITY="Apple Distribution" \
            CODE_SIGN_STYLE="Automatic" \
            DEVELOPMENT_TEAM="${{ secrets.APPLE_TEAM_ID }}" \
            PROVISIONING_PROFILE_SPECIFIER="match AppStore au.rhythmix.buddyapps"

      - name: Export IPA
        working-directory: ./capacitor-buddies/ios/App
        run: |
          xcodebuild -exportArchive \
            -archivePath DerivedData/App.xcarchive \
            -exportPath DerivedData/Export \
            -exportOptionsPlist ExportOptions.plist

      - name: Upload to TestFlight
        working-directory: ./capacitor-buddies
        env:
          APPLE_ID: ${{ secrets.APPLE_ID }}
          APPLE_ID_PASSWORD: ${{ secrets.APPLE_ID_PASSWORD }}
          APPLE_TEAM_ID: ${{ secrets.APPLE_TEAM_ID }}
          BUNDLE_ID: ${{ secrets.APPLE_BUNDLE_ID }}
        run: |
          xcrun altool --upload-app \
            --file DerivedData/Export/App.ipa \
            --type ios \
            --apiKey ${{ secrets.APPSTORE_CONNECT_API_KEY }} \
            --apiIssuer ${{ secrets.APPSTORE_CONNECT_API_ISSUER }}
```

Store this in `/home/user/jamie-wigg/capacitor-buddies/.github/workflows/ios-build.yml`.

## Step 5: Create ExportOptions.plist

Create `ios/App/ExportOptions.plist`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
	<key>teamID</key>
	<string>YOUR_TEAM_ID</string>
	<key>method</key>
	<string>app-store</string>
	<key>signingStyle</key>
	<string>automatic</string>
	<key>stripSwiftSymbols</key>
	<true/>
	<key>thinning</key>
	<string>&lt;none&gt;</string>
</dict>
</plist>
```

Replace `YOUR_TEAM_ID` with your 10-character Apple Team ID.

## Troubleshooting

### Build Fails: "Code Signing Error"

- Ensure `APPLE_TEAM_ID` is set correctly (no spaces, 10 chars)
- Check that the provisioning profile in Xcode matches the team ID
- Run locally first: `pnpm run build` → Xcode → **Product → Archive** (to test signing)

### TestFlight Upload Fails: "Invalid Credentials"

- Verify `APPLE_ID` and `APPLE_ID_PASSWORD` are correct
- Use an **App-Specific Password**, not your main Apple ID password
- If using Fastlane, regenerate the API key in App Store Connect

### Workflow Not Triggered

- Check the `on.push.paths` in the workflow — it only runs if `capacitor-buddies/**` or `apps/**` changed
- Or use `workflow_dispatch` to manually trigger in GitHub UI
