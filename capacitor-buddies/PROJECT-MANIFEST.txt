INITIAL SETUP STEPS
===================

1. Clone the repository:
   $ git clone <url> capacitor-buddies
   $ cd capacitor-buddies

2. Install Node dependencies:
   $ pnpm install

3. Build web assets and sync with Xcode:
   $ pnpm build
   (This runs: build:web + sync)

4. Open in Xcode:
   $ pnpm open:ios

5. In Xcode, configure signing (1 time):
   - Select "App" target
   - Signing & Capabilities tab
   - Enable "Automatically manage signing"
   - Select your Apple Team
   - Xcode creates provisioning profile automatically

6. Run in simulator:
   - Product → Destination → iPhone 16 Pro
   - Product → Run (Cmd+R)
   - App builds and launches

DEVELOPMENT WORKFLOW
====================

To update Buddy Apps:

1. Make changes in /apps/ folder
2. $ pnpm build:web         # Copy to www/
3. $ pnpm sync              # Sync to Xcode
4. Cmd+B in Xcode           # Rebuild
5. Cmd+R in Xcode           # Run

To make Capacitor config changes:

1. Edit capacitor.config.ts
2. $ pnpm sync
3. Cmd+B in Xcode
4. Cmd+R in Xcode

IMPORTANT NOTES
===============

⚠️  You need an Apple Developer account ($99/year) to:
   - Create App IDs
   - Generate provisioning profiles
   - Submit to TestFlight
   - Publish on App Store

⚠️  This is iOS-only. Android support can be added later with
   a separate capacitor-android/ project using the same www/ assets.

⚠️  Always test on a physical device before submitting to App Store.
   Simulator behavior may differ from real hardware.

⚠️  App Store review typically takes 24-48 hours.
   Common rejections: missing privacy policy, crashes, misleading description.

SUCCESS CRITERIA
================

After setup, you should be able to:

✓ Run `pnpm install` without errors
✓ Run `pnpm build` without errors
✓ Run `pnpm open:ios` and Xcode opens
✓ Build app in Xcode (Cmd+B) without errors
✓ Run app in simulator (Cmd+R) and see the landing page
✓ See Buddy Apps load when web assets are present
✓ See "Buddy Apps initialized successfully" in Xcode console

If any step fails, consult BUILD.md or DEVELOPMENT.md for troubleshooting.
