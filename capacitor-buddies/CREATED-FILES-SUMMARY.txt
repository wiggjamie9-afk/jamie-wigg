NEXT STEPS FOR USER:

1. READ: SETUP-CHECKLIST.md
   Follow the 13-phase checklist from dev setup through App Store submission.

2. INSTALL: pnpm install
   cd /home/user/jamie-wigg/capacitor-buddies
   pnpm install

3. BUILD WEB ASSETS: pnpm run build:web
   Copies all HTML files from ../apps/ to www/apps/

4. GENERATE iOS PROJECT: npx capacitor add ios
   Creates ios/App/ folder with Xcode project (first time only)

5. SYNC: pnpm run sync
   Copies www/ to iOS, installs CocoaPods

6. CONFIGURE: pnpm run open:ios
   Opens Xcode workspace to set Team ID and signing

7. TEST: Build in Xcode (Cmd+B) and run on simulator/device (Cmd+R)

8. SUBMIT: Follow APP-STORE-SUBMISSION.md to prepare for App Store review

9. AUTOMATE (Optional): Set GitHub Secrets and push to main for CI/CD
   See DEPLOYMENT.md for GitHub Actions setup
