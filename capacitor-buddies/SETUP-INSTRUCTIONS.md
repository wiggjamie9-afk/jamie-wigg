## Before You Start

### Prerequisites

1. **Apple Developer Account**
   - Free to start development
   - $99/year for App Store submission
   - Sign up: https://developer.apple.com/account

2. **Mac with Xcode 15+**
   - Download from Mac App Store (free)
   - Install Xcode Command Line Tools: `xcode-select --install`

3. **Node.js 20+ and pnpm 9+**
   ```bash
   # Check versions:
   node --version    # Should be v20.x.x or higher
   pnpm --version    # Should be 9.x.x or higher
   
   # If not installed:
   # Download Node from https://nodejs.org/ (v20 LTS)
   # Install pnpm: npm install -g pnpm@9
   ```

## 5-Minute Quick Start

```bash
# Step 1: Navigate to project
cd /home/user/jamie-wigg/capacitor-buddies

# Step 2: Install dependencies (2 minutes)
pnpm install

# Step 3: Build web assets and sync with Xcode (30 seconds)
pnpm build

# Step 4: Open Xcode project
pnpm open:ios

# Step 5: In Xcode, hit Cmd+R to run in simulator
# App should launch and display the landing page
```

Done! The app is now running in the iOS Simulator.

## Next Steps After Quick Start

### 1. Configure Xcode Signing (5 minutes)

In Xcode (which is still open from `pnpm open:ios`):

1. Click **App** in the left sidebar (under "Targets")
2. Go to **Signing & Capabilities** tab
3. Check **"Automatically manage signing"**
4. Select your **Apple ID** / **Team** from the dropdown
5. Xcode creates a provisioning profile automatically

Done! You can now build on physical devices.

### 2. Read the Documentation

In order (takes ~30 minutes total):

1. **QUICKSTART.md** — Already read (above)
2. **BUILD.md** — Xcode setup & simulator/device testing
3. **DEVELOPMENT.md** — Daily dev workflow
4. **APP-STORE-SUBMISSION.md** — When ready to publish

### 3. Test on Physical Device (Optional)

See **BUILD.md** for step-by-step instructions.

### 4. Update Buddy Apps

To include your Buddy Apps in the iOS wrapper:

```bash
# Copy apps/ from main repo to the build location:
pnpm build:web    # Copies /apps/ to www/

# Then rebuild:
pnpm open:ios     # Open Xcode
# In Xcode: Cmd+B to build, Cmd+R to run
```

### 5. Submit to App Store

See **APP-STORE-SUBMISSION.md** for:
- Creating app metadata

## Key Commands

```bash
# Install dependencies (1 time)
pnpm install

# Copy Buddy Apps from /apps/ to www/
pnpm build:web

# Sync www/ to Xcode project
pnpm sync

# Both above (recommended)
pnpm build

# Open Xcode with iOS project
pnpm open:ios

# Run unit tests
pnpm test
```

## Workflow: Update Buddy Apps

1. Modify or add apps in `/apps/` folder
2. Run `pnpm build:web` to copy to www/
3. Run `pnpm sync` to update Xcode
4. In Xcode: `Cmd+B` to build, `Cmd+R` to run
5. Test in simulator or on device

## Important Notes

⚠️ **iOS-Only For Now**
- This project targets iOS only (iPhone/iPad)
- Android support can be added later with a separate `capacitor-android/` project
- Both would use the same `www/` web assets

⚠️ **Always Test on Real Device Before App Store**
- Simulator behavior may differ from real hardware
- Real device testing is required before TestFlight submission

⚠️ **App Store Review Takes Time**
- TestFlight review: typically 24-48 hours
- App Store review: typically 24-48 hours
- Common rejections: missing privacy policy, crashes, misleading description

⚠️ **Need Apple Developer Account**
- Free to develop locally
- $99/year for App Store submission
- Sign up at https://developer.apple.com/account
