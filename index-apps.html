    Frequently Asked Questions

    Everything you need to know about getting started.

    Why do I need to enter my Claude API key? ▼

    We run entirely client-side. Your API key stays on your device—we never store it on our servers. This gives you full control and privacy. You can generate a free API key at console.anthropic.com.

    Are these apps really free? ▼

    Yes. All apps start completely free with core features. Premium features unlock at $2.99–$11.99/mo per app. Or get all 10 for $24.99/mo. You only pay for what you use, and you control your own API costs.

    How is my data handled? ▼

    We don't store your conversations, files, or personal data. Everything stays on your device or in your Claude API account. We use industry-standard HTTPS encryption. See our full privacy policy for details.

    Can I use these offline? ▼

    Most apps require an internet connection to access Claude API. However, we're building offline modes for Study Assistant and Habit Tracker using local AI models. Email us if offline support matters for your use case.

    Which app should I start with? ▼

    If you're a student, start with Study Assistant. If you're a professional, try Meeting Transcriber or Code Reviewer. If you want wellness, go with Fitness Coach. Not sure? Try Language Tutor—it's the most fun to explore.

    What about Android/iOS apps? ▼

    All apps run as progressive web apps (PWAs) that work on any device with a browser—mobile included. Just add to home screen on iOS or Android. Native iOS/Android apps are on our roadmap for 2025.
