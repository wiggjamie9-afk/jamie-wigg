## What's in this kit

- **kids-channel/BOOK-SEO-PACK.md** — full SEO pack (title, description, tags for all 35) + channel About + master tag set.
- **kids-channel/youtube-uploads/** — 35 paste-ready `.txt` files, one per video (title + description + hashtags + tags + settings).
- **thumbnails-sunny/** — 1280×720 YouTube thumbnails for all 35.
- **kdp-covers/** — 1600×2560 Amazon KDP portrait covers for all 35.
- Each **bookN/redesign/** folder holds that book's video (`*-video.mp4`), PDF, and page-flip eBook (`.epub`).

## To publish a video

1. Open the matching file in `youtube-uploads/` (e.g. `book34-dolphin.txt`).
2. Upload `bookN/redesign/*-video.mp4` to YouTube.
3. Copy the TITLE, DESCRIPTION, and TAGS from the txt file.
4. Set thumbnail from `thumbnails-sunny/`. Set **Made for kids: Yes**. Add to the playlist.

## To publish an eBook (Amazon KDP)

1. Upload `bookN/redesign/*.epub` and the cover from `kdp-covers/book0N-kdp-cover.jpg`.
2. Use the same title/description from the SEO pack. See `kids-channel/AMAZON-KDP-GUIDE.md` for the full walkthrough.
