# Printful Setup for Sunny's Cozy Bedtime Tales

## Step 1: Create Printful Account (Free)
- Go to: https://www.printful.com/
- Sign up with email
- Confirm email address
- No credit card required until first order

## Step 2: Connect Printful to Etsy Store
1. Log into Printful account
2. Click "Connect store"
3. Select "Etsy" from options
4. Click "Connect Etsy"
5. Sign in with your Etsy credentials
6. Authorize Printful to access your store
7. Printful will sync with your Etsy shop

## Step 4: Set Pricing in Printful
- Printful shows base production cost
- You set retail markup
- Recommended margins:
  - T-Shirt: $24.99 retail (Printful handles $7-10 cost)
  - Hoodie: $39.99 retail (Printful handles $18-22 cost)
  - Pajamas: $34.99 retail
  - Plushie: $24.99 retail
  - Pillow: $29.99 retail

## Step 5: Create Etsy Listings
Option A: **Automatic (Recommended)**
1. In Printful, click "Sync with store"
2. Printful auto-creates Etsy listings from uploaded designs
3. Edit titles, descriptions, tags in Etsy

Option B: **Manual**
1. Go to Etsy shop
2. Create new listing
3. Link to Printful product
4. Add product description
5. Set price

## Step 6: Linking Etsy to Your Shop

### If you already have Etsy shop:
1. Go to Printful → Connect store → Etsy
2. Authorize connection
3. Products auto-sync

### If you don't have Etsy shop yet:
1. Go to: https://www.etsy.com/sell
2. Create shop (free)
3. Shop name: "Sunny's Cozy Tales Shop" (or similar)
4. Add shop description
5. Upload shop logo
6. Then connect to Printful (see above)

## Step 8: Automate Order Fulfillment
1. Orders placed on Etsy → Printful notifies you
2. Printful handles: production, packing, shipping
3. You receive profit (retail price - Printful cost)
4. Customer receives tracking info automatically
5. No inventory, no shipping logistics

## Revenue Flow
```
Customer pays $24.99 (T-shirt)
         ↓
Etsy takes 5% fee = -$1.25
         ↓
Payment center: $23.74
         ↓
Printful cost: $8.00
         ↓
YOUR PROFIT: $15.74 per shirt
```
