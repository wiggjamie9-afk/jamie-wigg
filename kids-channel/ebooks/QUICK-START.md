## First-time setup (30 minutes)

### 1. Gumroad (5 min)
- Go to **gumroad.com** → Sign up
- Add payment method
- Done — you're ready to upload

### 2. Amazon KDP (10 min)
- Go to **kdp.amazon.com** → Sign in with Amazon account
- Create author profile
- Done

### 3. Etsy (15 min)
- Go to **etsy.com** → Sign up
- Open shop
- Add shop policies
- Done

## Per-episode workflow (30 minutes)

For each generated episode:

```
1. Episode generates → ebook.pdf created (AUTOMATIC ✅)

2. GUMROAD (5 min)
   • Go to gumroad.com → New Product → File
   • Select ebook.pdf
   • Title: "Sonny's Cozy Quokka Bedtime Tales — [Episode Name]"
   • Price: $3.99
   • Publish
   • Copy link → paste in YouTube description

3. AMAZON KDP (15 min)
   • Go to kdp.amazon.com → Create → Kindle eBook
   • Title: same as Gumroad
   • Upload ebook.pdf
   • Set price: $4.99
   • Add categories: Bedtime & Dreams / Animals
   • Add 7 keywords
   • Publish → get ASIN
   • Copy Amazon link → paste in YouTube description

4. ETSY (10 min)
   • Go to etsy.com → New Listing → Digital Download
   • Title: same as Gumroad
   • Upload ebook.pdf
   • Price: $3.99
   • Add tags (bedtime, children, picture book, etc.)
   • Publish
   • Copy Etsy link → paste in YouTube description

5. TRACKING (3 min)
   • Save links in checklist file
   • Add row to CSV with episode info
   • Done ✅
```

**Time per episode: ~30 minutes** (first few times)  
**Time per episode: ~15 minutes** (once you're familiar)

## 💡 Pro tips

- **Upload all 3 platforms same day** — maximizes exposure
- **Gumroad link in YouTube description first** — highest conversion
- **Update Amazon pricing later** — start at $4.99, adjust after month 1
- **Print-on-demand optional** — only if customers ask for physical books

## ❓ FAQ

**Q: Do I need different descriptions for each platform?**  
A: No, use the templates above. They work on all 3 platforms.

**Q: What if I want to sell physical printed books?**  
A: Amazon KDP offers print-on-demand. Set it up after Kindle version is live.

**Q: Can I use the same PDF on all platforms?**  
A: Yes! Same file, 3 platforms = 3 revenue streams.

**Q: How much time per episode?**  
A: 30 min first time. 10-15 min once you're comfortable.

**Q: Can I raise prices later?**  
A: Yes. Start at $3.99 (Gumroad), $4.99 (Amazon). Raise to $5.99–$7.99 after 3 months if selling well.
