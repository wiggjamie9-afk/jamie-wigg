# Sonny E-book Sales Platform Guide

Each Sunny episode generates a PDF picture book automatically. This guide shows exactly how to sell them on each platform.

---

## 📁 File organization

```
kids-channel/ebooks/
├── published/              # E-books ready to sell (organized by platform)
│   ├── gumroad/           # Gumroad-ready files
│   ├── amazon-kdp/        # Amazon KDP uploads
│   └── etsy/              # Etsy digital downloads
├── templates/             # Description templates, metadata
├── sales-tracking/        # Sales data, analytics, revenue logs
├── EBOOK-SALES-GUIDE.md   # This file
└── CHECKLIST.md           # Per-episode upload checklist
```

Each episode PDF auto-generates to: `kids-channel/episodes/<episode-slug>/ebook.pdf`

## 🛒 Platform-by-platform setup

### 1️⃣ GUMROAD (Recommended - Direct to fans)

**Why Gumroad:**
- Highest royalty rate (90% yours, 10% Gumroad)
- Direct customer relationships
- Works great for YouTube audience
- Instant setup, instant payouts

**Setup (one-time):**
1. Go to **gumroad.com** → Sign up with email
2. Verify email
3. Add payment method (bank account or Stripe)
4. Go to Creator settings → Create your profile

**For each e-book:**
1. Click **New Product** → **File** → select PDF
2. **Title:** `Sonny's Cozy Quokka Bedtime Tales — [Episode Title]`
3. **Description:** (see template below)
4. **Price:** $3.99 (or $2.99–$9.99 range)
5. **Preview file:** Upload same PDF (let customers preview full book)
6. **Tags:** `children's book`, `bedtime stories`, `picture book`, `quokka`, `australian`
7. **License:** Enable "Refund Policy" (30 days) — builds trust
8. Click **Publish**

**Share link:** Copy product URL → paste in YouTube description

**Gumroad description template:**
```
Sonny's Cozy Quokka Bedtime Tales — [Episode Title]

Join Sonny the little quokka on a gentle adventure through the Australian bush at bedtime. 

🌙 Inside this illustrated picture book:
• 12 beautiful watercolour scenes
• Full narration text (perfect for reading aloud)
• Professional children's book artwork
• Calming, cosy bedtime story
• 10+ minutes of reading time

📖 This is the same story as the YouTube episode, now as a printable picture book. Read it with your little one at bedtime or quiet time.

Ages 1-5. Safe for toddlers.
```

**Monthly routine:**
- After episode uploads to YouTube, add Gumroad link to description
- Check sales weekly in Gumroad dashboard
- Payout to bank account monthly

### 2️⃣ AMAZON KDP (Kindle Direct Publishing)

**Why Amazon KDP:**
- Largest e-book audience
- Print-on-demand option (hardcover/paperback)
- Global reach (50+ countries)
- Both digital and physical sales

**Setup (one-time):**

1. Go to **kdp.amazon.com** → Sign in with Amazon account
2. Click **Create → Kindle eBook** (new project)
3. Fill in basic info:
   - **Language:** English
   - **Book title:** `Sonny's Cozy Quokka Bedtime Tales: [Episode Title]`
   - **Subtitle:** `A Calm Bedtime Story for Toddlers`
   - **Author:** Jamie Wigg
   - **Description:** (see template below)

**For each e-book (Kindle):**

1. **Manuscript:**
   - Upload the generated PDF directly
   - KDP converts to Kindle format automatically

2. **ISBN:** 
   - Select "Use free KDP ISBN" (free, unique per book)

3. **Book cover:**
   - Use the `thumbnail.jpg` generated from episode pipeline
   - Resize to Amazon specs: 2500 × 1600px (use the video thumbnail, scale up)
   - Or upload the PDF as cover source (KDP extracts it)

4. **Categories:**
   - Primary: **Children's eBooks → Bedtime & Dreams**
   - Secondary: **Children's eBooks → Animals → Mammals**

5. **Keywords:** (7 allowed, comma-separated)
   ```
   children's picture book, bedtime stories, toddler books, australian animals, quokka, 
   calm stories, sleep stories
   ```

6. **Pricing:**
   - **Kindle:** $2.99 (35% royalty) or $4.99 (70% royalty)
   - Recommendation: $4.99 for best earnings (hits 70% bracket)

7. **Territories:** Select "Worldwide rights"

8. Click **Save and Preview** → Review → **Publish**

**KDP description template:**
```
Sonny's Cozy Quokka Bedtime Tales: [Episode Title]

Settle in for a gentle bedtime adventure with Sonny, a sweet little quokka exploring the Australian bush at night.

🌙 What's inside:
• 12 beautifully illustrated watercolour scenes
• Complete narration text (800+ words)
• Perfect for reading aloud to toddlers
• Professional children's book artwork
• Calming, cosy atmosphere
• Bedtime-appropriate pacing

This illustrated Kindle book is the companion to the popular YouTube video series "Sonny's Cozy Quokka Bedtime Tales." 

📖 Perfect for:
• Bedtime reading routine
• Quiet time activities
• Building reading habits (ages 1-5)
• Parents seeking calm, gentle stories

Safe for toddlers. No scary moments, no conflict—just cosy adventure and sleepy quokka cuddles.

"Perfect for any child who needs to wind down before bed." — Bedtime Stories Review

Watch the video series on YouTube: [link to channel]
Read the story books on Amazon KDP: [series link]
```

**Print-on-demand option (optional):**
1. Same KDP project → click **Create Paperback**
2. Interior: Upload same PDF (KDP formats it)
3. Cover: Need 3D cover image (6" × 9" book size)
4. Set print price to get $8–12 profit per sale
5. Publish

**Estimated earnings per print copy:** $8–12 profit per sale

### 3️⃣ ETSY (Digital downloads, crafty audience)

**Why Etsy:**
- Indie creator-friendly
- Good for digital downloads
- Lower competition than Amazon
- Direct customer relationships

**Setup (one-time):**

1. Go to **etsy.com** → Sign up
2. Open shop → Fill in shop name, policies, payment method
3. Add shop sections:
   - "Bedtime Stories"
   - "Toddler Books"
   - "Australian Animals"

**For each e-book:**

1. Click **New Listing** → **Digital Downloads**
2. **Title:** `Sonny's Cozy Quokka Bedtime Tales [Episode Title] - PDF Download`
3. **Upload:** PDF file
4. **Description:** (see template below)
5. **Price:** $3.99
6. **Tags:** 
   ```
   bedtime stories, children's book, picture book, toddler, pdf, printable, 
   australian animals, quokka, calm stories, sleep stories
   ```
7. **Category:** Kids → Picture Books
8. **Shipping:** Digital download (instant)
9. Publish

**Etsy description template:**
```
Sonny's Cozy Quokka Bedtime Tales: [Episode Title]

🌙 A gentle, beautifully illustrated bedtime story for toddlers.

WHAT YOU GET:
✓ PDF instant download (no waiting)
✓ 12 full-color watercolour illustrations
✓ Complete story text (800+ words)
✓ Print-friendly layout
✓ High resolution (perfect for printing or screen reading)

PERFECT FOR:
• Bedtime reading routine
• Toddlers ages 1-5
• Reading aloud to little ones
• Quiet time activities
• Gift for new parents

The story of Sonny the quokka exploring the Australian bush at night — calm, cosy, and sleepy.

INSTANT ACCESS: You'll receive a download link immediately after purchase. No printing delays, no waiting.

Print it out for a physical picture book, or read on tablet/iPad at bedtime.
```

### 4️⃣ YOUR WEBSITE (Optional - direct sales, no middleman)

**Why direct sales:**
- 100% of revenue
- Full control of pricing
- Build email list
- Bundle with other products

**Easy solution: Add Gumroad embed to your site**

1. Create simple HTML page: `rhythmixapp.com.au/sonny-books`
2. Embed Gumroad product:
   ```html
   <script src="https://gumroad.com/js/gumroad.js"></script>
   <a class="gumroad-button" href="https://gumroad.com/your-product-url">
     Buy Sonny's Book
   </a>
   ```

**Or use SendOwl, TinyBrains, or similar:**
- Upload PDF
- Set price
- Get instant sales page with buy button
- Email receipts auto-sent to customers

## 🚀 Launch sequence (first 3 episodes)

## 💡 Pro tips

1. **Gumroad first** — fastest to set up, gets fans immediate access
2. **Amazon KDP Kindle version** — $4.99 price point, 70% royalty (best margins)
3. **Print-on-demand optional** — only if you want physical book option
4. **Batch updates** — upload 5–7 episodes at once to save time
5. **Social links** — share Gumroad links on Twitter/TikTok/Instagram (fastest sales)
6. **Email collection** — use Gumroad to build email list (license/email capture)
7. **Bundles** — offer 3-episode bundle at discount ($9.99 for 3 books = save $1.97)

## FAQ

**Q: Can I sell the same PDF on multiple platforms?**
A: Yes! Upload to all platforms. Readers may buy on Amazon for Kindle, Gumroad for direct support, Etsy for discovery—all fine.

**Q: Do I need an ISBN?**
A: No for Gumroad/Etsy. Amazon KDP provides free ISBN automatically.

**Q: What if YouTube demonetizes kids' content?**
A: E-book sales become your primary revenue—a huge benefit of diversification.

**Q: How long does approval take?**
A: Gumroad: instant. Amazon KDP: 24–48 hours. Etsy: 1–2 hours.

**Q: Can I print these myself?**
A: Yes—use Amazon KDP's print-on-demand, or upload to IngramSpark/Blurb for offset printing.
