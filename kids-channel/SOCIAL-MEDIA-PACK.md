## Posting plan (suggested)

1. **Week 1:** Promo 1 everywhere (TikTok, IG Reels, FB, X) + set as YouTube channel trailer. Pin all 14 thumbnails to Pinterest.
2. **Ongoing:** one book per day/every other day — post the clip/caption to TikTok + IG Reels + FB using the per-book templates, always linking the full YouTube video.
3. **Re-run Promo 2** whenever you want a push aimed at parents (Sunday evenings work well — bedtime dread is real).
4. Always link back to YouTube; the channel is home base.
