🔑 Fix: YouTube OAuth (5 min)
1
Open Google Cloud Console

console.cloud.google.com → APIs & Services → Credentials

2
Find your OAuth 2.0 Client

Click it → copy the Client ID and Client Secret. If it's been deleted, create a new one: type = Desktop App.

3
Update GitHub Secrets

github.com → your repo → Settings → Secrets → Actions

  • YOUTUBE_CLIENT_IDClient ID from step 2
  • YOUTUBE_CLIENT_SECRETClient Secret from step 2
4
Run the auth script once

On your computer, from the repo folder:

python kids-channel/youtube_auth.py

Follow the link it prints → sign in → paste the code back. It saves kids-channel/token.json.

5
Paste new tokens into GitHub Secrets

Open kids-channel/token.json and update:

  • YOUTUBE_ACCESS_TOKENaccess_token value
  • YOUTUBE_REFRESH_TOKENrefresh_token value
6
