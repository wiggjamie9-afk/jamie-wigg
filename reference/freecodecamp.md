# freeCodeCamp.org — reference

Open-source codebase + curriculum of freeCodeCamp.org, a donor-supported 501(c)(3)
charity that teaches people to code for free. Pasted into the session; preserved here
as a reference pointer (it's a huge external monorepo — not vendored, not a plugin).

- Live: <https://www.freecodecamp.org>
- Repo: <https://github.com/freeCodeCamp/freeCodeCamp>
- License: software **BSD-3-Clause**; `/curriculum` learning resources © 2014 freeCodeCamp.org

## Full-Stack Developer Curriculum (free certifications)

Each cert = interactive lessons + workshops + labs + reviews + quizzes, plus **5 required
projects** to qualify for the exam; pass the exam to claim the cert.

- Responsive Web Design
- JavaScript
- Front-End Development Libraries
- Python
- Relational Databases
- Back-End Development and APIs

**Language certs** (organized into modules; complete all quizzes to sit the exam):
- A2 English for Developers (Beta)
- B1 English for Developers (Beta)
- A1 Professional Spanish (Beta)
- A1 Professional Chinese (Beta)

Interview prep bundled in: The Odin Project (freeCodeCamp Remix), Coding Interview Prep,
Project Euler, Rosetta Code. Also a free **Foundational C# with Microsoft** certification.

Certs are permanent (linkable from LinkedIn/résumé, employer-verifiable) — revoked only
on unambiguous Academic Honesty Policy violations (plagiarism).

## Contributing / reporting

- Bugs: read "how to report a bug", confirm it's new + reproducible, then open a GitHub issue.
- Security: follow the repo's security policy for responsible disclosure — don't file vulns as public issues.
- Contribution guide lives in the repo's `CONTRIBUTING`.

## Why it's here (not "installed")

This is a learning platform + curriculum, not a tool the agent runs. Clone the repo to
run the platform locally (see its `docs/`), or just use the hosted site. Kept as a
bookmark; not wired into `.claude/settings.json`.
