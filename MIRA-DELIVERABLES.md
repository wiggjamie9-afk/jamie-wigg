## 🎬 Animation Information

### Movement Philosophy
- **Grounded:** Stable, balanced movements
- **Present:** Intentional, purposeful actions
- **Warm:** Open, welcoming gestures
- **Calm:** Smooth, natural motion
- **Supportive:** Movements communicate care

### Key Animation Principles
- Smooth, natural transitions
- Natural breathing patterns
- Purposeful gestures
- Warm, kind expressions
- Grounded, stable stance
- Authentic emotional expressions

### Timing Guidelines
- **Walking step:** 0.3-0.5 seconds
- **Expression change:** 0.15-0.33 seconds
- **Gesture:** 0.25-0.5 seconds
- **Head movement:** 0.25-0.5 seconds

### Expression Transitions
Each expression can transition smoothly to others:
- Smile ↔ Listening (thoughtful)
- Listening ↔ Concerned (caring)
- Concerned ↔ Supportive (action)
- Listening ↔ Playful (joy)

## 🎯 Usage Guidelines

### DO's
✓ Use consistent color palette  
✓ Maintain clean bold-line style  
✓ Keep expressions warm and kind  
✓ Show grounded, balanced posture  
✓ Emphasize listening and support  
✓ Use natural, smooth movements  
✓ Maintain authentic emotional expressions  

### DON'Ts
✗ Don't change core color palette  
✗ Don't add complex shading or gradients  
✗ Don't distort character proportions  
✗ Don't make expressions cold or distant  
✗ Don't use jerky or mechanical movement  
✗ Don't break character personality  
✗ Don't create inauthentic emotional expressions
