## Design Style Specifications

### Visual Approach: 2D Cartoon Illustration

#### Line Work
- **Style:** Clean, bold lines
- **Weight:** Consistent stroke weight (approximately 2-3 pixels at reference size)
- **Quality:** Confident, smooth curves
- **Clarity:** Every line serves a purpose; no unnecessary details

#### Color Application
- **Method:** Flat colors (no gradients or complex shading)
- **Approach:** Solid fill colors with simple line definitions
- **Depth:** Achieved through layering and line placement, not shading
- **Consistency:** Same colors across all variations

#### Animation Readiness
- **Simplicity:** Design optimized for animation (easy to redraw)
- **Consistency:** All angles and poses maintain visual coherence
- **Modularity:** Head, body, limbs drawn as separate clear elements
- **Stroke Clarity:** Every element clearly defined for animation cleanup

#### Proportions
- **Head Size:** Slightly larger than realistic (cartoon proportion)
- **Eyes:** Large and expressive (key to emotion communication)
- **Body:** Youthful, approachable proportions
- **Overall:** Balanced and appealing, not exaggerated

## Animation Notes

### Key Points for Animators
1. **Consistency:** All variations maintain same proportions and style
2. **Simplicity:** Design intended for hand-drawn or digital frame-by-frame animation
3. **Color Flatness:** No shading means simple fills and no gradient complexity
4. **Expression Focus:** Eyes are most important for emotional communication
5. **Modularity:** Head and body can be separated for animation efficiency

### Recommended Animation Approach
- Frame-by-frame animation (hand-drawn digital)
- Puppet-pin rigging (for motion graphics)
- 3D model texturing from this 2D reference (if needed)
