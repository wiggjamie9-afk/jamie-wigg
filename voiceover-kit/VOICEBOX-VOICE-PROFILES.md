## How to Set Up Profiles in Voicebox

### Option A: Clone from Episode 1 MP3s
1. Open Voicebox → Voice Profiles
2. Click "New Profile"
3. Upload your Episode 1 MP3 (or select the audio segment with the intro narration)
4. Name it (e.g., `miguel-clone`, `katherine-clone`)
5. Voicebox will auto-detect and clone the voice
6. Repeat for each unique voice

### Option B: Use Preset Voices
1. Open Voicebox → Voice Profiles
2. Select a preset from Kokoro (50 voices) or Qwen CustomVoice (9 voices)
3. Name it with a matching label
4. No cloning needed

**Once profiles are created, fill in the "Profile Name" column above with the exact names you use in Voicebox.**
