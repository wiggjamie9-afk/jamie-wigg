TEST SCENARIOS COVERED
================================================================================

✅ Auth Flow
   1. Register user (email, name, password)
   2. Verify JWT issued
   3. Login with credentials
   4. Verify token with /verify endpoint
   5. Use token in subsequent requests

✅ Voice Processing
   1. Upload audio recording (base64)
   2. Emotion detection (7 emotions: happy, sad, angry, neutral, surprised, fearful, disgusted)
   3. Acoustic features extraction (pitch, speech rate, jitter, formants, MFCC, prosody)
   4. Transcription generation (Claude)
   5. List all recordings
   6. Fetch specific recording with full analysis

✅ Decisions & Metacognition
   1. Create decision with:
      - Title, description, options, chosen option, reasoning
      - Category (career, health, relationship, etc.)
      - Confidence level
      - 4-pillar metacognitive scores:
        * Planning clarity (1-10)
        * Monitoring comprehension (1-10)
        * Evaluation effectiveness (1-10)
        * Reflection insights (yes/no)
   2. Claude generates decision analysis
   3. Metacognitive score calculated: (P + M + E + R) / 4 * 100
   4. Store decision with full metadata
   5. Fetch decision with analysis
   6. Analyze patterns (avg score, confidence, category breakdown)

✅ Twin Interactions
   1. Get all 9 Twins:
      - Task (productivity)
      - Coach (guidance with metacognitive focus)
      - Growth (learning)
      - Health (wellness)
      - Relationship (connection)
      - Financial (money)
      - Creative (expression)
      - Research (knowledge)
      - Metacognition (thinking about thinking)
   2. Send message to Twin
   3. Claude generates context-aware response
   4. Store interaction with metadata
   5. Fetch Twin interaction history (30 recent)
   6. Test with different metacognitive phases (planning, monitoring, evaluating, reflecting)

✅ 8-Layer Coherence
   Layer 1: Heart-Brain Coherence (from HRV)
   Layer 2: Breathing Coherence (from breathing rate)
   Layer 3: Brain Coherence (simulated)
   Layer 4: Vagal Tone (from heart rate)
   Layer 5: Circadian Alignment (from sleep data)
   Layer 6: Biofield Coherence (simulated)
   Layer 7: Decision-Value Alignment (from decisions)
   Layer 8: Metacognitive Coherence (from decision metrics)
   
   Calculations:
   - Overall = weighted average of 8 layers
   - State = coherent (>70) | transitioning (50-70) | stressed (<50)
   - Trend = improving | stable | declining
   - Recommendations generated by Claude

✅ Knowledge & Learning
   1. Create knowledge entries (topic, insight, source, evidence)
   2. Group by topic
   3. Create learning loop (cycle, type, key insights)
   4. Claude analyzes patterns across entries and decisions
   5. Fetch loop history (12 recent)

✅ Accessibility
   1. Book scanning: upload image → Claude Vision extracts text
   2. Text simplification: for dyslexia/ADHD readers
   3. Reading time estimation
   4. TTS endpoint: text + speed → audio URL (simulated)
   5. Settings management: get/update preferences

✅ Error Scenarios
   - 401 on missing/invalid JWT
   - 400 on validation failure (missing fields, invalid format)
   - 404 on non-existent resource
   - 409 on duplicate email
   - 500 on server error (graceful with logging)

✅ Performance
   - Measure p50, p95, p99 latency for each endpoint
   - Default targets: p99 < 5000ms (except Claude endpoints)
   - Generate performance-results.json report

================================================================================
TROUBLESHOOTING
================================================================================

Issue: Connection refused (port 5000)
Solution:
  $ lsof -i :5000
  $ npm run dev &
  $ sleep 5

Issue: Database connection error
Solution:
  $ psql -U postgres -d neural_twin_dev -c "SELECT 1"
  $ docker start postgres  (if using Docker)
  $ npm run prisma:migrate

Issue: Invalid JWT token
Solution:
  $ JWT=$(curl -s -X POST http://localhost:5000/api/auth/register -H "Content-Type: application/json" -d '{"email":"test@example.com","name":"Test","password":"SecurePass123!"}' | jq -r '.token')
  $ echo $JWT

Issue: Claude API key not working
Solution:
  $ echo $ANTHROPIC_API_KEY | head -c 20
  $ curl https://api.anthropic.com/v1/auth/check -H "x-api-key: $ANTHROPIC_API_KEY"

Issue: Performance tests show high latency
Solution:
  $ time curl https://api.anthropic.com/v1/messages \
      -H "x-api-key: $ANTHROPIC_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{model":"claude-opus-4-8","max_tokens":100,"messages":[{"role":"user","content":"hi"}]}'
  (Claude API latency affects all analysis endpoints)
