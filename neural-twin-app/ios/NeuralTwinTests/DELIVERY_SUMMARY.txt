MOCK OBJECTS REFERENCE
================================================================================

MockURLSession:
- Intercepts URLSession.data(for:) calls
- setMockResponse(data:statusCode:) for success paths
- setMockError(_:) for network failures
- lastRequest property to verify request details

MockTokenStore:
- In-memory token storage (no UserDefaults)
- saveSession(token:userId:email:name:)
- setToken(_:), setUserId(_:), setEmail(_:), setName(_:)
- clear() to reset state
- isLoggedIn computed property

MockData:
- 9 pre-built JSON response strings
- createAuthResponse(userId:email:name:token:)
- createVoiceRecordingResponse(id:primaryEmotion:confidence:)
- jsonData(_:) helper for String→Data conversion

To integrate into your Xcode project:

1. ✅ Create new "Unit Testing Bundle" target named "NeuralTwinTests"
2. ✅ Copy test files to NeuralTwinTests/ directory
3. ✅ Update test target's Build Settings:
       - Bundle Identifier: com.example.neuraltwin.tests
       - iOS Deployment Target: 14.0+
4. ✅ Ensure classes/enums have public access:
       - APIClient, APIError
       - AuthResponse, LoginRequest, RegisterRequest
       - VoiceRecordingResponse, DecisionResponse, etc.
       - TokenStore
5. ✅ Update APIClient to accept optional URLSession injection
6. ✅ Update TokenStore to support test initialization
