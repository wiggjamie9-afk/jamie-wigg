## Just getting started?

Don't curate. Dump everything you have here as `.md` / `.txt` — saved
articles, Kindle highlights, podcast notes, meeting transcripts, project
docs, old decision memos, screenshots. Original filenames are fine. The
agent renames and indexes on ingest.

If you have nothing to dump, save a 20-minute conversation about your
work and goals as `memory.md` and start there.

## Conventions (post-ingest)

- Once ingested, files are referred to by descriptive kebab-case slugs,
  ideally date-prefixed: `2025-03-eu-ai-act-summary.pdf`,
  `lex-fridman-2024-12-anthropic.txt`. The agent may rename files on
  ingest if it makes the slug clearer — that's fine.
- Sources are **immutable** after ingest. If you need to correct or
  annotate, do it in the wiki, not the source file.
- One row per file. Link the **Summary** column to
  `../wiki/summaries/summary-<slug>.md`.
