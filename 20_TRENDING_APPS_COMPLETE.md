## Deployment Steps

### Step 1: Build APK Bundle (Capacitor/Cordova)

```bash
# Install Capacitor
npm install @capacitor/core @capacitor/cli

# Initialize for each app
npx cap init com.rhythmix.heartbeat --web-dir=apps/

# Add Android platform
npx cap add android

# Build APK
cd android && ./gradlew assembleRelease
# Output: android/app/build/outputs/apk/release/app-release.apk
```

### Step 2: Sign APK

```bash
jarsigner -verbose -sigalg SHA1withRSA -digestalg SHA1 \
  -keystore my-release-key.jks \
  app-release.apk alias_name
```

### Step 3: Upload to Google Play Console

1. **Create product listing** (app name, category, content rating)
2. **Upload signed APK** to internal testing first
3. **Test on 5+ real devices** (different screen sizes, Android versions)
4. **Upload screenshots + assets**
5. **Set pricing** (free or subscription tier)
6. **Configure in-app purchases** (premium features)
7. **Submit for review** (24–72 hour review cycle)
