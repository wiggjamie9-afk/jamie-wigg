# MS. CHEN - Character Design Project

## Overview

This project contains the professional character design specification and generation instructions for **MS. CHEN**, an East Asian music teacher and healthy adulthood mentor figure for the RHYTHMIX platform.

MS. CHEN represents what neurodivergent individuals can aspire to in adulthood: grounded, graceful, wise, present, and genuinely mentoring others while honoring their own creative sensitivity and humanity.

## Quick Start: Generating the Character Design

### Option A: Direct Generation (No Setup Required)
1. Go to [Replicate.com](https://replicate.com) or use any FLUX 1.1 Pro interface
2. Open `ms-chen-character-sheet.md`
3. Copy the **GENERATION PROMPT** section
4. Paste into your image generation interface
5. Set dimensions to **1920×1080** (16:9 aspect ratio)
6. Generate and save to `outputs/ms-chen-character-design-sheet.png`

### Option B: Using Claude Code (With API Token Setup)
```bash
# From repo root, first set up your Replicate token:
cp .claude/settings.local.json.example .claude/settings.local.json
# Edit .claude/settings.local.json and add your REPLICATE_API_TOKEN

# Then generate:
/dream MS. CHEN character design sheet - [copy prompt from GENERATION PROMPT section]
```

## Character Summary

### Identity
- **Name**: MS. CHEN
- **Role**: Music teacher, neurodivergent mentor
- **Age**: Adult (40s-50s)
- **Ethnicity**: East Asian heritage
- **Function**: Shows what healthy, grounded adulthood looks like

### Visual Identity
- **Skin**: Warm medium-brown (#8B6F47)
- **Hair**: Long dark (#2c1810), styled gracefully
- **Eyes**: Wise, kind, patient—deep listening and understanding
- **Outfit**: Deep teal cardigan (#1B5E5E) over cream shirt
- **Accents**: Gold jewelry and details (#DAA520)
- **Posture**: Graceful, rhythmic, suggesting musical sensitivity

### What She Represents
- Wisdom (accessible, not distant)
- Grounded strength (stable, rooted)
- Musical sensitivity (as a feature, not a flaw)
- Authentic mentorship (teaching, listening, creating, supporting)
- Healthy neurodivergent adulthood (present, grounded, creative, genuine)

## Four Mentor Poses

1. **Teaching/Conducting** — Arms raised, confident, inspiring (she can guide)
2. **Listening Attentively** — Leaned forward, engaged, present (she hears you)
3. **Playing/Moving with Music** — Joyful, rhythmic, embodied (she experiences joy)
4. **Hand-on-Shoulder** — Warm, reassuring, supportive (she believes in you)

Together they show: **The complete mentor**

## Key Design Principles

### 1. Accessible Wisdom
Not intimidating. Wisdom is achievable. Maturity is attainable.

### 2. Grounded Presence
Stable, rooted, centered—while remaining graceful and creative.

### 3. Musical Sensitivity
Music and rhythm are integral to her being, not decorative.

### 4. Authentic Mentorship
Multifaceted: she teaches, listens, creates, and supports.

### 5. Neurodivergent Representation
Shows that sensitivity, grace, and creative intensity can coexist with groundedness and wisdom.

### Common Issues

→ Regenerate with stronger expression directives; see prompt customization guide

**Character doesn't feel like a mentor?**
→ Add emphasis on mentorship qualities; revisit `DESIGN-RATIONALE.md` for reference

**Layout isn't balanced?**
→ Ensure dimensions are exactly 1920×1080; verify central figure prominence
