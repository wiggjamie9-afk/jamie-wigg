### 🎯 CRITICAL GAPS (Phase 2-3)

#### 1. **Grammar & Writing Support**
Dyslexic readers struggle with grammar, not just reading.

**Features Needed:**
- [ ] **Grammar Highlighter** - Color-code sentence parts (subject/verb/object)
- [ ] **Word Type Indicator** - Hover to see if word is noun/verb/adjective/adverb
- [ ] **Sentence Complexity Indicator** - Rate sentence difficulty (simple/moderate/complex)
- [ ] **Spelling Support** - Underline unusual spellings, offer alternatives
- [ ] **Sentence Rewriter** - "Simplify this sentence" (use Claude API)

**Why it matters:** Dyslexia affects written expression, not just reading. A struggling writer can't learn if text is too complex grammatically.

**Example:**
```
Original: "The cat's refusal to move from beneath the heavy curtains demonstrated its desire for solitude."
Simplified: "The cat would not move from under the curtains. It wanted to be alone."
```

---

#### 2. **Interactive Manipulatives**
Abstract math becomes concrete with interactive tools.

**Features Needed:**
- [ ] **Number Lines** - Drag to add/subtract
- [ ] **Fraction Bars** - Visual fractions, drag to compare
- [ ] **Base-10 Blocks** - See regrouping in place value
- [ ] **Geometric Shapes** - Rotate, measure, calculate properties
- [ ] **Function Graphers** - Plot functions, see effects of changes
- [ ] **Algebra Tiles** - Visualize equations, solve by moving tiles
- [ ] **Probability Spinners** - Spin to understand probability

**Example:**
```
Student types: "What is 1/2 + 1/4?"
System shows: Visual fraction bars + interactive model
Student can drag bar segments to see answer = 3/4
Tutor explains: "See? Two quarters in a half, plus one quarter = three quarters"
```

---

#### 3. **Mistake Diagnosis (Not Just Answers)**
Current: Shows steps. Needed: **Identifies WHY student made mistake.**

**Features Needed:**
- [ ] **Common Misconception Detection** - "You're forgetting to flip the fraction in division"
- [ ] **Error Pattern Recognition** - "You've made this mistake 3 times. Let's fix it."
- [ ] **Targeted Remediation** - If student struggles with fractions, get extra practice
- [ ] **Confidence Scoring** - Not just right/wrong, but "how sure are you?"
- [ ] **Uncertainty Support** - If low confidence → get extra explanation even if right

**Example:**
```
Problem: 3/4 ÷ 1/2
Student answer: 3/8 (wrong)
System detects: Student forgot to flip second fraction
Response: "When dividing fractions, flip the second one! So 3/4 × 2/1 = 6/4 = 3/2"
Then: 5 similar practice problems on this rule
```

---

#### 4. **Multiple Explanation Styles**
Not all brains learn the same way.

**Features Needed:**
- [ ] **Visual Explanation** - Draw it out
- [ ] **Verbal Explanation** - Speak it (narrated by TTS)
- [ ] **Written Explanation** - Step-by-step text
- [ ] **Concrete Example** - Show real-world use
- [ ] **Analogical Explanation** - "It's like..."
- [ ] **Hands-On Activity** - Interactive practice

**Example (Solving x + 5 = 12):**
```
Visual: Show 12 dots, 5 highlighted, remaining counted
Verbal: "We have 12 total. Five are already counted. How many more?"
Written: "x + 5 = 12 → x = 12 - 5 → x = 7"
Concrete: "You have $12. You spent $5. How much left? $7."
Analogy: "It's like finding what was before we added 5"
```
