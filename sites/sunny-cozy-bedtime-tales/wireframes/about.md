# Wireframe: /about

## S1 Hero

**Layout**: Full-width hero section with text overlay on soft illustrated background.

**Background**: Warm, calming gradient (cream #F5F0EB → pale gold) or soft watercolor illustration of a sleeping child, moon, and stars.

**Text Placement**: Center-aligned, overlaid text.

**Content Blocks**:
```
Headline:     "About Sunny's Cozy Bedtime Tales"
Subheadline:  "Professional calming stories for peaceful sleep"
CTA Button:   "Subscribe on YouTube" (navy #192D55 background, cream text)
              (Secondary: "Shop Merchandise" button outline)
```

**Interactive Elements**:
- Primary CTA button links to YouTube channel
- Secondary button links to /shop

**Dimensions**: Full viewport width, 300-400px height on mobile, 500-600px on desktop.

## Responsive Breakpoints

- **Desktop**: 1200px+ (2-column layouts, full-width sections)
- **Tablet**: 768px–1199px (2-column layouts scaled, larger padding)
- **Mobile**: <768px (single-column stack, reduced padding, larger touch targets)

---

## Key Accessibility Notes

- Form labels: Associate labels with input fields (use `<label for="...">`)
- Icons: Provide alt text or aria-labels for all icons/buttons
- Color contrast: Ensure navy/gold/cream combinations meet WCAG AA (4.5:1 for body text)
- Interactive elements: Min 44px × 44px touch target on mobile
- Keyboard nav: Tab order should follow visual flow (Hero → Creator → Mission → Credentials → Contact → Footer)
