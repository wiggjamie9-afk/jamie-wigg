The 4 Core Concepts

Every agent is defined by these pillars

Agent

The personality and role of your AI. Choose a model, set temperature, define tools, and craft the system prompt that guides behavior.

Environment

The runtime configuration. Specify model, temperature, max tokens, tools, and system instructions that shape responses.

Session

Memory and context management. Set session duration, choose memory type (conversation, context-window), and define lifecycle.

Events

Lifecycle hooks for automation. Trigger actions on session_start, message_sent, tool_used, and session_end.
