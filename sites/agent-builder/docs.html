API Documentation

Integrate Agent Builder into your applications with our REST API

Base URL

https://api.agentbuilder.com/v1

Authentication

Bearer token in Authorization header. Learn more

Authentication

Bearer Token Authentication

All API requests require authentication using a Bearer token in the Authorization header. You can obtain your API key from your account settings after signing up.

API Key Management

Your API key grants full access to your account and agents. Treat it like a password—never commit it to version control or share it publicly. Rotate your key periodically from the account settings page.

Authorization Header Format

Authorization: Bearer YOUR_API_KEY

Rate Limiting

Endpoints

GET
/agents
Stable

Description: List all agents for the authenticated user.

Query Parameters

Parameter Type Description
type string (optional) Filter by agent type: code-review, document-processing, research, security-audit, data-analysis, customer-support
limit number (optional) Maximum number of results (default: 20, max: 100)
offset number (optional) Pagination offset (default: 0) 
curl -X GET https://api.agentbuilder.com/v1/agents \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json"
const response = await fetch('https://api.agentbuilder.com/v1/agents', {
  method: 'GET',
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
  }
});

const agents = await response.json();
console.log(agents);

POST
/agents
Stable

Description: Create a new agent. Returns the agent configuration with generated ID.

Request Body

Field Type Description
name string Agent display name (max 100 chars)
type string One of: code-review, document-processing, research, security-audit, data-analysis, customer-support
description string (optional) Agent description (max 500 chars)
tier string One of: starter, pro, addon
environment object (optional) Model and configuration settings 
curl -X POST https://api.agentbuilder.com/v1/agents \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Security Audit Agent",
    "type": "security-audit",
    "description": "Scans code for vulnerabilities",
    "tier": "pro",
    "environment": {
      "model": "claude-opus-4.8",
      "temperature": 0.2,
      "max_tokens": 2048
    }
  }'

  tier: "pro",

DELETE
/agents/:id
Stable

Description: Delete an agent and all associated data. This action is permanent.

Path Parameters

Parameter Type Description
id string The agent UUID 
curl -X DELETE https://api.agentbuilder.com/v1/agents/agent-uuid-123 \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json"
const agentId = 'agent-uuid-123';
const response = await fetch(`https://api.agentbuilder.com/v1/agents/${agentId}`, {
  method: 'DELETE',
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
  }
});

if (response.status === 204) {
  console.log('Agent deleted successfully');
}
Status: 204 No Content

{
  "success": true,
  "message": "Agent deleted successfully",
  "id": "agent-uuid-123"
}
GET
/analytics
Stable

Description: Retrieve analytics data for your agents. Shows usage, success rates, and costs.

Query Parameters

Parameter Type Description
agent_id string (optional) Filter by specific agent ID
date_from string (optional) Start date (ISO 8601 format)
date_to string (optional) End date (ISO 8601 format)
metric string (optional) One of: sessions, messages, tokens_used, success_rate, cost 
curl -X GET 'https://api.agentbuilder.com/v1/analytics?agent_id=agent-uuid-123&date_from=2024-01-01&date_to=2024-01-31' \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json"
const params = new URLSearchParams({
  agent_id: 'agent-uuid-123',
  date_from: '2024-01-01',
  date_to: '2024-01-31',
  metric: 'success_rate'
});

const response = await fetch(`https://api.agentbuilder.com/v1/analytics?${params}`, {
  method: 'GET',
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'

});

const analytics = await response.json();

Error Handling

The API uses standard HTTP status codes to indicate success or failure.

Status Code Meaning Description
200 OK Request succeeded
201 Created Resource created successfully
204 No Content Successful deletion
400 Bad Request Invalid request format or parameters
401 Unauthorized Missing or invalid API key
403 Forbidden Insufficient permissions for this resource
404 Not Found Agent or resource not found
429 Too Many Requests Rate limit exceeded
500 Internal Server Error Server error; try again later

Error Response Format

Error responses include a machine-readable error code and human-readable message:

{
  "error": {
    "code": "INVALID_REQUEST",
    "message": "Missing required field: name",
    "details": {
      "field": "name",
      "reason": "required"
    }
  }
}

Webhooks

Webhooks allow you to receive real-time notifications about agent events. Configure them in your account settings.

Webhook Events

Event Trigger Payload
agent.created New agent created Agent object
agent.updated Agent configuration changed Agent object
agent.deleted Agent deleted Agent ID
session.started Agent session begins Session object
session.completed Agent session ends Session metrics

Best Practices

1. API Key Security

  • Store API keys in environment variables, not in code
  • Rotate keys every 90 days
  • Use different keys for development and production
  • Revoke keys immediately if compromised

2. Error Handling

  • Always check HTTP status codes
  • Implement exponential backoff for retries
  • Log detailed error information for debugging
  • Handle rate limits gracefully

3. Performance

  • Cache agent configurations locally when possible
  • Use pagination for large result sets
  • Batch operations when available
  • Monitor response times and optimize queries

4. Reliability

  • Implement request idempotency where needed
  • Use webhooks instead of polling when possible
  • Monitor API status page for incidents
  • Test with staging agents before production
