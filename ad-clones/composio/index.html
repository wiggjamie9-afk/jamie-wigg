How it works

Three lines of code,
1,000+ tools unlocked.

Conduit handles auth, rate limits, retries, and schemas so your agent can just call tools. Drop into any LLM framework: OpenAI, Anthropic, LangChain, LlamaIndex, custom.

PYTHON · agent.py
# 1. install + auth
from conduit import Conduit
tools = Conduit().tools("slack", "gmail", "linear")
 
# 2. give them to your model
response = client.chat.create(
  model="claude-opus-4-7",
  tools=tools,
  messages=[{"role": "user",
    "content": "Find the open Linear bugs assigned to Maya, post a summary in #eng-standup, and email me the report."}]
)
 
# 3. that's it. Conduit handles auth, retries, schemas.

FAQ

Quick answers.

Which LLMs does Conduit support?

Anthropic, OpenAI, Google Gemini, Mistral, and Ollama. The SDK auto-formats tool schemas to match the active provider — same code works across all of them.

Can I add my own internal tools?

Yes. The Conduit CLI wraps any HTTP endpoint into a typed tool in under five minutes, including auth, schemas, and rate limits.

How do you handle per-user credentials?

Every credential is encrypted at rest with KMS, scoped to a single end-user, and rotated automatically. You never see a raw token.

Is the SDK open source?

Yes — MIT licensed. Self-host the gateway too if you'd like; Enterprise plans include support for it.

What's a "tool call" for billing?

One outbound API call to a third-party tool — e.g. one Slack message, one Linear issue created. Internal Conduit ops (auth, schema gen) are free.
