## Next: Setup Print-On-Demand

### Option 1: Etsy + Printful (Recommended) ⭐

**Why Etsy + Printful?**
- Zero setup fee
- Zero inventory cost
- Printful handles production + shipping
- Automatic order fulfillment
- Connected ecosystem

**Steps:**
1. **Create Etsy Shop** (if you don't have one)
   - Go to: https://www.etsy.com/sell
   - Click "Start selling"
   - Choose shop name (e.g., "SunnyCozyTales")
   - Basic info (your location, language)
   - Free to create

2. **Create Printful Account**
   - Go to: https://www.printful.com/
   - Sign up (free)
   - No credit card yet

3. **Connect Etsy to Printful**
   - Log into Printful
   - Dashboard → "Connect store"
   - Select "Etsy"
   - Click "Connect Etsy"
   - Sign in with Etsy credentials
   - Authorize Printful

4. **Upload Designs**
   - In Printful: "Add product"
   - Select product type (T-Shirt, Hoodie, etc.)
   - Upload PNG file (we created these)
   - Position design on product template
   - Set dimensions and placement
   - Repeat for all 5 products

5. **Create Listings**
   - Printful can auto-create Etsy listings
   - Or manually create in Etsy shop
   - Add product description (templates in setup guide)
   - Set price (recommend prices above)
   - Publish

6. **Start Selling**
   - Orders → Etsy → Printful
   - Printful handles: production, packing, shipping
   - You get paid: retail price - Etsy fee - Printful cost

**Revenue Example:**
- Customer pays: $24.99 (T-shirt)
- Etsy fee (5%): -$1.25
- Printful cost: -$8.00
- **Your profit: $15.74** (no work, no inventory)

### Option 2: Amazon Merch on Demand

**Why Amazon Merch?**
- Massive reach (Amazon customer base)
- Same zero-inventory model
- Only T-shirts + hoodies available
- Tier-based (must apply for approval)

**Steps:**
1. Apply at: https://merch.amazon.com/
2. Wait for approval (1-2 weeks)
3. Upload designs (T-shirt + Hoodie only)
4. Create listings
5. Amazon handles fulfillment

**Limitation:** Only T-shirts and hoodies available (not pajamas, plushie, pillow)

---

### Option 3: Shopify + Print Node / Printful

**Why Shopify?**
- Full brand control
- Custom domain
- More customization
- Professional storefront

**Why not for now?**
- $29/month subscription
- More setup complexity
- Not needed until you have significant traffic

**Recommendation:** Start with Etsy + Printful (free), then move to Shopify later if needed.
