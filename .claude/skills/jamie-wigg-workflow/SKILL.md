# jamie-wigg workflow

Project-specific glue for this repo. The hyperframes/remotion/gsap skills cover their own domains — this skill covers things that only matter inside `jamie-wigg`.

## When this skill is relevant

- Editing TypeScript inside `video/src/`
- Running `npm run lint` / `npm run dev` / `npx remotion render`
- Modifying skills in `.agents/skills/` and questioning whether `skills-lock.json` matters
- Cleaning up `graphify-out/` or `text*.txt` scratch
- Branch hygiene (which branch should I be on?)

## Lint after every Remotion edit

The `video/` subproject has TypeScript and ESLint. After ANY edit to `video/src/**/*.tsx` or `.ts`:

```bash
cd video && npm run lint
```

This runs `eslint src && tsc`. If `tsc` fails, the render will fail too — do not skip.

## Two copies of the skills (this is normal)

- `.agents/skills/<name>/` — canonical source, edit here.
- `~/.claude/skills/<name>/` — installed copy that Claude actually loads, hash-tracked in `skills-lock.json`.

Editing `.agents/skills/` does NOT update what Claude loads in this session. To make a local edit visible, copy the file across:

```bash
cp -r .agents/skills/<name>/. ~/.claude/skills/<name>/
```

The hash in `skills-lock.json` will then mismatch — that's expected for local edits and only matters if you're syncing back to the upstream `heygen-com/hyperframes` repo.

## Branch convention

Sessions push to `claude/new-session-XXXXX` (the value comes from the session prompt). Never force-push or push to `main`. The global Stop hook will refuse to let the session end with uncommitted or unpushed work.

## Files to leave alone

- `graphify-out/**` — generated, regenerated by graphify
- `text*.txt` — scratch HTML/CSS fragments, not wired to anything
- `video/.remotion/` — Remotion build cache
- `video/node_modules/` and root `node_modules/` (if any)

## Render output location

`npx remotion render` defaults to `video/out/<composition>.mp4`. Don't commit it — `out/` is not in `.gitignore` yet, so move/delete renders before committing or add `video/out/` to `.gitignore` first.
