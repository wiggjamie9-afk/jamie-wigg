### Technique 3: Prompt Caching (Memory + Speed)

**What it is:**
Reuse expensive prompts. Ask once, cache the result, use it 1,000 times.

**How it works:**
```python
# Without caching:
100 brains all use the same system prompt
Each brain processes prompt = 100× cost

# With caching:
System prompt cached at start of day
100 brains reuse cached prompt
Cost = 1/100th

Savings: 99% on repeated prompts
Speed: 2× faster (read from cache)
```

**Real example:**
```
Brand guidelines system prompt: 5,000 tokens
All 100 brains use it: cached once
Per brain, reuse costs: 10% of original
Savings: ~$5–$10/brain/month
```

**Why it matters:**
Same quality output, 10× cheaper to run.

### Technique 4: Few-Shot Learning (Learn from Examples)

**What it is:**
Show the brain examples of what you want, and it learns the pattern.

**How it works:**

**Why it matters:**
The brain learns what works (from real historical data) and replicates it automatically.

### Technique 5: Chain-of-Thought Prompting (Step-by-Step Reasoning)

**What it is:**
Ask the brain to show its work, step by step.

**How it works:**
```python
# Bad prompt:
"What price should I set for my app?"
Output: "$9.99"
(You don't know why)

# Good prompt with chain-of-thought:
"What price should I set for my app? Think step-by-step:
1. What's our target market? (early adopters, price-sensitive, etc.)
2. What's our cost per user? (API costs, server costs)
3. What's our target margin? (gross profit %)
4. What do competitors charge?
5. What's the price elasticity? (higher price = fewer users)
6. Given all above, what price maximizes profit?

Show your reasoning at each step."

Output:
1. Target market: tech-savvy, willing to pay for quality
2. Cost per user: $0.50/month
3. Target margin: 80%
4. Competitors: $4.99–$19.99
5. Elasticity: price increase 1% → users down 0.3%
6. Optimal price: $14.99 (balances volume × margin)

Recommendation: Start at $14.99, A/B test $9.99 and $19.99 to find optimal
```

**Why it matters:**
The brain doesn't just give you an answer — it explains its reasoning. You understand WHY and can trust it.
