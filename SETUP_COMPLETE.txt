STEP 1: Set Up Android SDK (Choose One Method)
---------------------------------------------

Option A: GUI (Android Studio - recommended for UI development)
  1. Download from: https://developer.android.com/studio
  2. Run installer, follow wizard
  3. Select Android SDK, build-tools, platform-tools
  4. Takes ~30 minutes and ~10 GB disk space

Option B: Command-line (minimal, ~500 MB)
  1. Create directory: mkdir -p ~/Android/Sdk
  2. Download cmdline-tools from: https://developer.android.com/studio#cmdline-tools
  3. Extract to ~/Android/Sdk/cmdline-tools/latest/
  4. Run: sdkmanager "platforms;android-35" "build-tools;35.0.0"
  5. Takes ~10 minutes and ~1 GB disk space

For detailed instructions:
  bash SETUP-ANDROID-SDK.sh
  cat ~/.android_sdk_setup_instructions.txt

STEP 2: Configure Environment
-----------------------------

Add to ~/.bashrc, ~/.zshrc, or ~/.profile:
  export ANDROID_SDK_ROOT=$HOME/Android/Sdk
  export ANDROID_HOME=$ANDROID_SDK_ROOT
  export PATH=$ANDROID_SDK_ROOT/cmdline-tools/latest/bin:$PATH
  export PATH=$ANDROID_SDK_ROOT/platform-tools:$PATH

Then reload:
  source ~/.bashrc  # or source ~/.zshrc
