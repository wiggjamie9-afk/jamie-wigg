DEPLOYMENT STEPS:
==================

Day 1 - Setup (30 minutes):
  1. pip install google-auth-oauthlib google-auth-httplib2 google-api-python-client python-dotenv
  2. Download OAuth credentials from Google Cloud Console as youtube_oauth_credentials.json
  3. python3 setup-youtube-channel.py

Day 2 - Test (20 minutes):
  1. python3 upload-book-to-youtube.py --book 1
  2. Verify in YouTube Studio

Day 3 - Deploy (3-4 hours):
  1. python3 batch-upload-all-books.py
  2. Monitor console output

Day 4 - Verify (30 minutes):
  1. python3 verify-youtube-uploads.py
  2. Check YouTube Studio

Day 5 - Go Live (30 minutes):
  1. Make videos public in YouTube Studio
  2. Promote on social media

QUOTAS & LIMITS:
=================

YouTube API:
  - 10,000 units/day (resets midnight PST)
  - 10 requests/second
  - Cost per upload: ~1,700 units (video + playlist + thumbnail)
  - 17 books = ~28,900 units (well within limit)

Video Upload:
  - Max file size: 256GB
  - Supported formats: .mp4, .mov, .avi, etc.
  - Takes 5-8 minutes per upload (varies by size)
  - Total batch: ~2.5 hours for 17 books

Batch Upload:
  - Default interval: 60 seconds
  - Configurable: --delay flag
  - Recommended: 60-120 seconds (respects quotas)
  - Can adjust: python3 batch-upload-all-books.py --delay 120

KNOWN LIMITATIONS:
===================

1. Cannot create new channels via API
   - Channel must exist before setup
   - Workaround: Use existing YouTube account

2. Cannot delete videos via API (by design)
   - Use YouTube Studio for deletions
   - Videos remain in channel after removal from playlist

3. Cannot update existing videos
   - Can change metadata in Studio
   - Cannot replace video file directly
   - Workaround: Delete and re-upload

4. Thumbnail 404s may occur initially
   - YouTube processes images asynchronously
   - Wait 5-15 minutes before refreshing
   - Or re-upload manually in Studio

5. Playlist ordering can take time to sync
   - Position updates sometimes delayed
   - Refresh YouTube Studio page to see changes
