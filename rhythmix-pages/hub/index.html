FAQ

Quick answers.

Which agents and frameworks does Hub support?

Anthropic, OpenAI, Google Gemini, Mistral, Ollama, LangChain, custom. The SDK auto-formats tool schemas to match the active provider — same code works across all of them.

Can I add my own internal tools?

Yes. The Hub CLI wraps any HTTP endpoint into a typed tool in under five minutes, including auth, schemas, and rate limits.

How do you handle per-artist credentials?

Every credential is encrypted at rest with KMS, scoped to a single artist or seat, and rotated automatically. You never see a raw token.

Is the SDK open source?

Yes — MIT licensed. Self-host the gateway too if you'd like; Label plans include support for it.

What's a "platform call" for billing?

One outbound API call to a third-party platform — e.g. one TikTok upload, one Spotify pre-save link. Internal Hub ops (auth, schema gen) are free.

Does Hub take royalties?

No. Flat subscription. Royalty data flows through Hub but is never touched or split.
