Quickstart install

If you want to run your own instance of the engine, in most cases the best way is to use the rhythmix-studio CLI.

From your Gumroad receipt, download the latest rhythmix-studio.zip bundle and unzip it:

unzip rhythmix-studio.zip
cd rhythmix-studio
npm install

Then, for a free dry-run plan — no API calls, no cost — pass --dry-run to see the scene breakdown and estimated render spend before committing:

node bin/rhythmix-studio.mjs plan path/to/your-track.mp3 \
  --theme "neon-soaked midnight city" \
  --bpm 120 \
  --dry-run

Or to run a real render against your own Replicate account (typically $8–25 for a 60-second video, depending on which models the planner routes to):

export REPLICATE_API_TOKEN=r8_...
node bin/rhythmix-studio.mjs render path/to/your-track.mp3 \
  --theme "underwater cathedral, bioluminescent fish" \
  --bpm 92 \
  --aspect 16:9

Your finished video lands at ./rhythmix-out/<track-name>/final.mp4.

No computer? Use a browser

iPad-only or Chromebook? Open the repo in GitHub Codespaces and run bash rhythmix-studio/demo.sh in the terminal. The .devcontainer/ config pre-installs Node, ffmpeg, and aubio. Free for 60 hours/month on any GitHub account.

Source modes

Pick a source mode that fits your budget. The engine compiles your track the same way in all three:

FREE — your own clips

node bin/rhythmix-studio.mjs render your-track.mp3 \
  --theme "midnight rooftop" \
  --bpm 120 \
  --source local \
  --clips-dir path/to/folder-of-mp4s

FREE — Pexels stock footage

export PEXELS_API_KEY=...
node bin/rhythmix-studio.mjs render your-track.mp3 \
  --theme "underwater cathedral, bioluminescent fish" \
  --bpm 92 \
  --source pexels

Get a free Pexels API key at pexels.com/api.

PAID — Replicate (Kling, Hunyuan, Luma, MiniMax)

export REPLICATE_API_TOKEN=...
node bin/rhythmix-studio.mjs render your-track.mp3 \
  --theme "Australian outback at golden hour, vintage muscle car" \
  --bpm 100 \
  --aspect 16:9 \
  --concurrency 3

Get a token at replicate.com/account/api-tokens. Always --dry-run first to see the cost estimate.

Requirements

  • Node.js 20 or newer — nodejs.org
  • ffmpeg and ffprobe on your PATH (Mac: brew install ffmpeg · Windows: winget install ffmpeg)
  • One of: a Replicate API token (paid), a Pexels key (free), or your own video clips (free, --source local)
  • Optional: aubio for auto-BPM detection (brew install aubio). Without it, pass --bpm <n> or accept un-snapped cuts.

Production renders

For longer tracks, higher resolutions, or batch jobs, run the engine on a beefier machine and stream the output back. The pipeline is checkpoint-friendly — if a render fails mid-way (network blip, API timeout), just re-run the same command. Finished scenes are kept; only the failed scene retries (up to 3× with backoff).

Check out the in-bundle QUICKSTART.txt for the full operations guide, plus everything you need to wire up your own theme presets or work with the planner API.
