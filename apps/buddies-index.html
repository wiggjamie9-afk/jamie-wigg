Get Started

Everything you need to know about setup, testing, and deployment.

⚙️
One-Time Setup
npm install && node avatar-proxy-local.mjs

This keeps your Higgsfield secret server-side (not in the browser). Takes 30 seconds.
📱
Test on Phone
python3 -m http.server 8000

Then open http://<your-mac-ip>:8000/apps/buddies.html
🚀
Deploy Anywhere
GitHub Pages, Vercel, Netlify, or your own server. Static HTML files. No backend required.
