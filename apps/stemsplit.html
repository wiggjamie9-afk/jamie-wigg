⚙︎ Settings (Bring your own key)

Get one at replicate.com/account/api-tokens. Stored only in this browser (localStorage). Sent only to Replicate via your proxy.
Replicate blocks direct browser calls (CORS). You must deploy a proxy. This repo ships one at studio/workers/replicate-proxy — run wrangler deploy there and paste its URL above. The repo Worker exposes /api/replicate-proxy/v1/*; leave the checkbox unticked for it.
How do I set this up? (1‑minute guide)
  1. Create a Replicate token at replicate.com/account/api-tokens and paste it above.
  2. Deploy the proxy: from studio/workers/replicate-proxy/ run wrangler deploy.
  3. Copy the deployed URL (e.g. https://replicate-proxy.you.workers.dev) into the proxy field.
  4. Open replicate.com/ryan5453/demucs, copy the current version hash, and (optionally) update DEMUCS_VERSION near the top of this file if separation 422s on version.
  5. Tap Save settings, then Separate stems.
