# AI Event Platform Academy — Complete Playbook

## The Concept

**Name:** `EventAI Academy`

**Tagline:** "Build, automate, and monetize your event platform in 90 days"

**Positioning:** A hands-on, project-based academy teaching solopreneurs and small teams how to build a production-grade event management platform with AI automation, real-time sync, and cross-device capabilities.

**Student outcome:** By week 12, every graduate has:
1. A deployed event platform (custom domain)
2. AI-powered event creation and search
3. Mobile iOS app
4. Automated social media posting and email
5. First customers paying them (the "$1K in 90 days" goal)

## The 90-Day Curriculum

### Week 1-2: Foundation & Planning
**Theme:** "Your event platform from zero to prototype"

- **Module 1:** Event platform strategy (who you're building for, revenue model)
- **Module 2:** Tech stack overview (React, Supabase, Capacitor, AI, automation)
- **Module 3:** Environment setup (local dev, deployment prep)
- **Module 4:** "Steal like an artist" — studying 3 existing event platforms

**Deliverable:** Planning doc + tech architecture diagram
**Checkpoint:** Deploy a blank event platform to Cloudflare

---

### Week 3-4: Frontend Foundation
**Theme:** "Build the interface users will fall in love with"

- **Module 5:** Event platform UI (forms, lists, detail pages with Tailwind)
- **Module 6:** Real-time sync (Supabase → React state, WebSocket subscriptions)
- **Module 7:** Theme system (two-color branding, accessibility)
- **Module 8:** Mobile-first design (responsive patterns, touch interactions)

**Deliverable:** Functional event creation + list UI, real-time working
**Checkpoint:** Create 3 test events, see them sync live

---

### Week 5-6: Data & Backend
**Theme:** "The engine that powers everything"

- **Module 9:** Database schema design (events, attendees, allottees, relationships)
- **Module 10:** API endpoints (CRUD, search, real-time)
- **Module 11:** Authentication & authorization (RLS policies, Supabase Auth)
- **Module 12:** Deployment (Next.js static export, Cloudflare Pages)

**Deliverable:** Production-grade API with tests, RLS policies working
**Checkpoint:** Deploy to custom domain, live database

---

### Week 7-8: AI & Automation (The Money Layer)
**Theme:** "Turn AI into revenue"

- **Module 13:** Semantic event search (natural language → relevant results)
- **Module 14:** AI image generation (Replicate/Leonardo for event posters)
- **Module 15:** Auto-caption generation (Whisper for video content)
- **Module 16:** Content automation (scripts, thumbnails, social copy)

**Deliverable:** AI-powered features fully integrated, generating monetizable content
**Checkpoint:** Generate 10 event posters + captions automatically

---

### Week 9-10: Cross-Platform & Mobile
**Theme:** "iPhone to web — everywhere at once"

- **Module 17:** Capacitor iOS wrapper (native app from web code)
- **Module 18:** Maps & geolocation (Leaflet integration, event discovery by location)
- **Module 19:** Offline-first sync (PWA patterns, background sync)
- **Module 20:** Push notifications (Capacitor + Firebase)

**Deliverable:** iOS app + PWA both working, location-based event discovery live
**Checkpoint:** Download from Apple TestFlight, create event from phone

---

### Week 11: Monetization & Growth Automation
**Theme:** "How to charge your first customers"

- **Module 21:** Pricing models (subscription, per-event, marketplace commission)
- **Module 22:** Payment integration (Stripe, PayPal setup)
- **Module 23:** Workflow automation (n8n for email, social, notifications)
- **Module 24:** Email agent (Agentic Inbox for customer support)

**Deliverable:** Payment processing working, automated workflows live
**Checkpoint:** Successfully process first test payment

---

### Week 12: Launch & Scale
**Theme:** "Go live and land your first paying customer"

- **Module 25:** Pre-launch (landing page, waitlist, press/social strategy)
- **Module 26:** Launch week (go public, first customers, support playbook)
- **Module 27:** Post-launch (iterate based on feedback, add features)
- **Module 28:** Scale playbook (hiring, outsourcing, next features)

**Deliverable:** Live platform with 3-10 paying customers (mini version of $1K goal)
**Checkpoint:** First customer payment received, testimonial captured

---

### Optional Modules (Add-on for Premium students)

- **Module 29:** Advanced AI agents (LangGraph for complex workflows)
- **Module 30:** Visual automation (Open Design for event marketing materials)
- **Module 31:** Conversational AI (Hermes for customer support bot)

## The Learning Format

### Core: Project-Based Learning
Each student builds **their own real event platform** from week 1-12.

- **Week 1-4:** Follow exact tutorial, match reference architecture
- **Week 5-8:** Customize for their niche (weddings, tech conferences, marathons, etc.)
- **Week 9-12:** Launch with their own branding and first customers

### Weekly Rhythm (Pro/Premium tiers)

**Every Tuesday, 11 AM ET (1 hour)**
- Week's theme walkthrough
- Live Q&A + troubleshooting
- Code review (if submitted)

**Every Friday, 5 PM ET (30 min)**
- Accountability + wins
- Social media brainstorm for launches
- Networking (student intros)

### Content Format

- **Code templates** (Git repos) — Cloneable starting points
- **Runbooks** (documented steps) — Copy/paste setup guides

```

Week 4: Event UI built + syncing live
```
