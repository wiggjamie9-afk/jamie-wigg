# Real AI Portraits for the Buddy Carousel

The carousel (`apps/buddies.html`) shows a designed art card for every buddy,
and **automatically upgrades** each card to a real photoreal portrait the moment
`apps/portraits/buddy-<id>.jpg` exists. No code change needed once the images
land — the card just swaps art → photo.

Portraits are generated by **Higgsfield Soul** in the cloud (GitHub Actions),
so you don't need a Mac or any local setup. You only do the 2-minute secret
setup once.

---

## One-time: add your Higgsfield keys as GitHub secrets

1. Get your keys from Higgsfield (dashboard → API): `HIGGSFIELD_API_KEY` and `HIGGSFIELD_SECRET`.
2. On GitHub, open the repo → **Settings → Secrets and variables → Actions → New repository secret**.
3. Add two secrets:
   - Name `HIGGSFIELD_API_KEY` → value = your key
   - Name `HIGGSFIELD_SECRET` → value = your secret

That's it. The keys stay encrypted in GitHub; they're never in the code.

---

## Generate the 50 portraits

1. GitHub repo → **Actions** tab → **Generate Buddy Portraits** → **Run workflow**.
2. Leave "Regenerate all" off the first time → **Run workflow**.
3. Wait ~3–5 minutes. The job generates all 50 photos and commits them to
   `apps/portraits/`.
4. GitHub Pages redeploys automatically. Open the carousel and the cards now
   show real faces.

## Re-rolling the look

- **Don't like a style?** Edit the `STYLE` line or a buddy's `subject` in
  `scripts/generate-portraits.mjs`, then run the workflow with
  **"Regenerate all" = on**.
- Each buddy's prompt is tuned to its role (e.g. Fitness Coach = athletic,
  Elderly Companion = warm older person), all sharing one cohesive
  studio-portrait style so the set feels like one product.

---

## How the auto-upgrade works

In each card:

```html
<img class="hero-photo" src="portraits/buddy-7.jpg"
     onload="this.classList.add('loaded')" onerror="this.remove()">
```

- **Photo exists** → it loads, fades in over the art, becomes the card hero.
- **No photo yet** → `onerror` removes the tag, the designed gradient art shows.

So the experience is great immediately and gets better automatically.
