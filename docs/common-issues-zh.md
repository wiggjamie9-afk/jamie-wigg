## 关于 STARLIGHTMIX Studio

### Q：STARLIGHTMIX Studio 是什么？

STARLIGHTMIX Studio 是一款移动端优先的网页应用，让你无需安装任何软件，即可将自己的音乐轨道生成 AI 音乐视频。你上传一段音频，选择视觉主题，Studio 便会通过你自己的 Replicate 账户生成一段 AI 视频并下载到你的设备。

### Q：Studio 需要安装应用吗？

不需要。直接通过浏览器访问 [studio.starlightmix.com](https://studio.starlightmix.com)，无需安装任何 App。Safari、Chrome、Firefox 均支持。

### Q：我的音频会上传到你们的服务器吗？

**不会。** 你的音频文件始终保存在你的设备本地（浏览器内存中），不会上传到我们的服务器。生成的视频也会直接下载到你的设备，不会存储在我们这里。

### Q：视频生成费用由谁承担？

由你自己的 Replicate 账户承担。Studio 不代收任何生成费用；所有 AI 生成请求直接计入你的 Replicate 账单。在你确认开始渲染之前，Studio 会先显示预估费用供你参考。

## 访问与许可证激活

### Q：我买了许可证，但无法登录，怎么办？

1. 打开 Studio 主页（`studio.starlightmix.com`），在许可证输入框中粘贴你在 Gumroad 收到的许可证密钥。
2. 如果提示「无效许可证」，请检查密钥是否复制完整，确认没有多余空格。
3. 如果问题持续，回复你的 Gumroad 收据邮件，将「许可证密钥」和「购买订单号」一并发送给我们。

### Q：许可证验证显示「网络错误」？

许可证验证需要连接验证服务器。请检查你的网络连接是否正常，然后刷新页面重试。如果持续出错，可能是临时性服务问题，请稍后再试或联系支持。

### Q：换了一台设备后许可证失效了，怎么办？

许可证密钥可以在多台设备上使用（具体台数见你购买时的说明）。在新设备上重新访问 Studio，重新输入你的许可证密钥即可激活。

### Q：什么是「终身许可」？

一次购买，终身使用当前版本所有功能，无需订阅或续费。后续功能更新详情以购买时的说明为准。

## Replicate API Token

### Q：Replicate API Token 在哪里获取？

1. 访问 [replicate.com](https://replicate.com)，注册或登录账户。
2. 进入账户设置 → API Tokens，创建一个新 Token。
3. 复制 Token 后，粘贴到 Studio 的「设置 → Replicate API Token」输入框中。

### Q：Token 填入后提示「无效 Token」？

- 确认 Token 以 `r8_` 开头（Replicate 官方 Token 的格式）。
- 确认复制时没有遗漏字符或带入多余空格。
- 前往 [replicate.com](https://replicate.com) 确认该 Token 仍处于有效状态（未被手动吊销）。

### Q：我的 Token 安全吗？

你的 Replicate Token 仅保存在**你的浏览器本地存储**中，经 AES-GCM 加密（由你设置的密码派生密钥），不会发送到我们的服务器。关闭标签页后，解密密钥会从内存中清除。

### Q：Token 的费用怎么控制？

建议在 [Replicate 后台](https://replicate.com/account/billing) 设置月度消费上限，以避免意外超支。Studio 在生成前会显示预估成本，你可以在确认前查看并取消。

## 音频上传

### Q：支持哪些音频格式？

支持 **MP3、WAV、M4A、FLAC**，文件大小上限为 **50 MB**。

### Q：上传音频后提示「文件过大」？

请将文件压缩至 50 MB 以下。建议：
- 使用 MP3 格式（128kbps 以上）可大幅缩小文件体积。
- 如果是 WAV 无损格式，转换为 MP3 后通常可减少 70%–80% 大小。

### Q：支持上传多轨混音吗？

目前仅支持单一立体声混音文件（已合并的最终混音），不支持多轨分离上传。

### Q：上传后浏览器崩溃或页面无响应？

Safari（尤其 iOS 上）在处理大文件时可能因内存不足而崩溃。建议：
- 压缩音频文件至 20 MB 以下。
- 关闭其他占用内存的标签页。
- 使用最新版 Safari 或 Chrome。

## 视频生成

### Q：生成一个视频需要多长时间？

一段 60 秒的视频通常在 **15 分钟以内**完成（取决于 Replicate 服务器负载和你的网络速度）。生成过程中可以看到每个场景的实时进度。

### Q：某个场景生成失败，整个视频会作废吗？

不会。失败的场景会自动重试最多 3 次。若重试仍失败，Studio 会用占位帧（黑底＋场景信息）代替，其余场景正常生成。你可以在完成后单独重新生成失败的场景，无需为成功的场景重新付费。

### Q：生成到一半页面关了，进度会丢失吗？

会丢失。请在生成过程中保持 Studio 标签页开启、不要锁屏或让浏览器进入后台太久（尤其是 iOS 上）。

### Q：可以在生成前修改场景安排吗？

可以。Studio 会在你确认渲染之前展示一个「计划预览」页面，你可以：
- 更换每个场景使用的 AI 模型
- 编辑每个场景的提示词（Prompt）
- 调整场景时长（自动对齐到最近的节拍）

### Q：视频下载后在哪里？

生成完成后 Studio 会自动触发浏览器下载，文件保存在你设备的「下载」文件夹中。同时，最近 50 次渲染记录会保存在 Studio 的「媒体库」页面，你可以随时重新下载。

### Q：打开了两个 Studio 标签页，会有影响吗？

Studio 会检测到多个标签页同时打开，并在两个标签页中都显示提示横幅，让你选择使用哪个标签页。建议同时只开启一个标签页，避免重复生成消耗 Replicate 额度。

## 浏览器兼容性

### Q：支持哪些浏览器？

| 浏览器 | 支持状态 |
|---|---|
| Safari（iOS 16+） | ✅ 推荐（首选） |
| Chrome（Android / 桌面） | ✅ 支持 |
| Firefox（桌面） | ✅ 支持 |
| Safari（macOS） | ✅ 支持 |
| 微信内置浏览器 | ⚠️ 不推荐（功能受限） |
| IE / 旧版 Edge | ❌ 不支持 |

### Q：提示「浏览器不支持 WebCrypto / IndexedDB / WebAssembly」？

这些是 Studio 的核心依赖项。请升级你的浏览器到最新版本：
- **iOS：** 升级到 iOS 16 及以上，使用 Safari。
- **Android：** 升级到最新版 Chrome。
- **桌面：** 使用 Chrome 108+、Firefox 110+、或 Safari 16.4+。

## 本地数据与隐私

### Q：Studio 在本地存储哪些数据？

| 数据类型 | 存储位置 | 说明 |
|---|---|---|
| Replicate Token（加密） | localStorage | 仅本地，AES-GCM 加密 |
| 许可证密钥 | localStorage | 仅本地 |
| 渲染历史与缩略图 | IndexedDB | 最多 50 条，超出自动清除最旧记录 |
| 计划草稿 | localStorage | 按计划 ID 存储 |

**不存储：** 音频文件内容、渲染完成的 MP4 Blob（超出历史上限后自动清除）。

### Q：如何清除所有本地数据？

进入 **设置 → 清除所有本地数据**，确认后将清除：
- Replicate Token
- 许可证密钥
- 所有渲染历史与缩略图
- 计划草稿

适用于出售或转让设备前的数据清理。

### Q：如何导出「支持包」供客服排查问题？

进入 **设置 → 导出支持包**，会下载一个 JSON 文件，包含：
- 最近的错误日志
- 浏览器信息（UA、分辨率、功能支持情况）
- ffmpeg.wasm 版本
- 计划历史元数据（不含音频内容、Token 或视频文件）

回复你的 Gumroad 收据邮件时附上此文件，有助于我们快速定位问题。

## 错误信息说明

| 错误提示 | 原因 | 解决方法 |
|---|---|---|
| `Invalid license key` | 许可证密钥不正确或已失效 | 检查密钥格式，或联系支持 |
| `Invalid Replicate token` | Token 格式错误或已被吊销 | 在 Replicate 后台重新生成 Token |
| `File too large` | 音频文件超过 50 MB | 压缩或转换格式后重新上传 |
| `WebCrypto not supported` | 浏览器版本过旧 | 升级浏览器 |
| `Replicate API unreachable` | 网络问题或 Replicate 服务故障 | 检查网络，稍后重试 |
| `Scene generation failed (3 retries)` | 该场景 AI 生成持续失败 | 使用场景「重新生成」按钮单独重试 |
| `Studio is open in another tab` | 检测到多个标签页 | 关闭其他 Studio 标签页，继续使用当前页面 |
| `ffmpeg.wasm failed to load` | WASM 模块加载失败（网络或内存不足） | 刷新页面，或关闭其他标签页释放内存 |
