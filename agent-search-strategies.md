# Background Agent Search Strategies
## For Verifying Cross-Generational Narrative Appeal Sources

### Overview
This document provides proven search tactics for locating, extracting, and verifying claims about multi-generational media consumption and narrative engagement. Use these strategies when background agents return.

## 1. PARROT ANALYTICS: Family Content Report Search

### Strategy A: Direct Website Search
```
Site: parrotanalytics.com
Search terms:
  - "family content" 2024 2025 2026
  - "YouTube family audience"
  - "multi-generational viewing"
  - "age-span appeal"
```

### Strategy B: Press Release & Blog Archives
```
Search: "Parrot Analytics" + "family content" + YouTube
  → Check parrotanalytics.com/insights/
  → Check parrotanalytics.com/news/
  → Look for published case studies
```

### Strategy C: Third-Party Citations
```
Search: "Parrot Analytics" + "family" + "YouTube" + "2024 OR 2025 OR 2026"
  → Look for industry articles citing Parrot Analytics data
  → Verify original report link from citation
```

**Data extraction points:**
- % viewership across age groups
- Engagement metrics by age span
- Retention rates for family content
- Publication date & report title

**Red flags:**
- Undated reports → mark as "publication date not specified"
- Claims without percentages → mark as "qualitative only"
- Extrapolated data vs. directly measured → note source

## 4. GOOGLE SCHOLAR: Narrative Psychology & Multi-Age Engagement

### Strategy A: Direct Scholar Search
```
scholar.google.com
Search queries (each search separately):
  1. "narrative engagement" "multi-age audience"
  2. "cross-generational appeal" psychology
  3. "family narrative" media consumption
  4. "narrative comprehension" age groups
  5. "storytelling" retention multi-generational
```

### Strategy B: Journal-Specific Searches
Key journals to search within:
- **Communication Research**
- **Journal of Broadcasting & Electronic Media**
- **Media Psychology**
- **Narrative Inquiry**
- **Journal of Media Psychology**
- **Psychology of Popular Media**

### Strategy C: Author-Following Strategy
```
Find key authors on the topic:
  - See who's cited most in early results
  - Search their publication list
  - Check their recent papers (2023+)
  - Look for review articles (synthesize multiple studies)
```

**Data extraction points:**
- Engagement % increase with narrative (vs. non-narrative)
- Age groups showing highest engagement
- Narrative elements that drive cross-age appeal
- Retention/completion rates by age
- Psychological mechanisms (explanation of WHY)

**Red flags:**
- Study sample size (n < 50 = smaller study, note it)
- Lab study vs. real-world data → important distinction
- Theory paper vs. empirical study → verify which it is
- Paywalled paper (can't verify claim) → mark "full text not accessible"

## 7. GENERAL FACT-CHECKING PROTOCOL

### When extracting any claim:

1. **Record the original statement verbatim**
   ```
   Original: "Family-focused narratives have 42% higher viewer retention"
   ```

2. **Identify the data point**
   ```
   Data: 42% (higher retention)
   Metric: Viewer retention rate
   Baseline: Non-narrative family content
   ```

3. **Note the scope**
   ```
   Population: YouTube viewers
   Age range: Not specified / 5–65+
   Geography: US-only / Global
   Sample size: n = [if available]
   ```

4. **Record publication info**
   ```
   Source: YouTube Creator Insider
   Publication date: March 2025
   URL: [full URL]
   Access: Public / Paywalled / Institutional
   ```

5. **Verify recency**
   ```
   3-year rule: Is publication 2023 or later? ✓ / ✗
   If older: Note "published 202X, may be outdated"
   ```

6. **Flag contradictions**
   ```
   Does this claim contradict Source A? YES / NO / UNCLEAR
   If yes: "Source A claims 35%, Source B claims 42%. [Possible explanation]"
   ```

## 9. CITATION FORMATS (For Final Report)

### APA Format
```
Author(s). (Year). Title of report. Publisher. Retrieved from URL
YouTube Creator Insider. (2025). Family content retention strategies. YouTube. Retrieved from https://youtube.com/creators/...
```

### Chicago (Notes) Format
```
Author/Organization. "Title." Publication, date. Accessed [date]. URL.
YouTube Creator Insider, "Family Content Retention Strategies," March 2025, https://youtube.com/...
```

### Plain Text (Minimal)
```
[Source] ([Year]). "[Claim]" - [Data point] ([URL])
YouTube Creator Insider (2025): "Family narratives drive 42% higher retention" (https://...)
```
