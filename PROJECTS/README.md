# PROJECTS

Active project briefs go here, one markdown file per project.

Existing in this repo:

- **trendbot** (`/src`) — global trend aggregator + AI drafter + Reddit publisher
- **pulse** (`/web`) — handcrafted landing page for the trend engine

Add new projects as `PROJECTS/<slug>.md` with:

```
# <project name>

## What
One sentence.

## Why
What problem does this solve for me / who's it for?

## Done looks like
Concrete success criteria.

## Open questions
Things I haven't decided yet.

## Status
not started / in progress / shipped / paused / killed
```
