# jamie-wigg

A Remotion video project for **RHYTHMIX** (AI music platform). The landing-page copy in `text*.txt` is the source material; the video in `video/` is the promo built from it.

## Repo map

- `video/` — the Remotion project. All video work happens here.
  - `src/Root.tsx` — registers compositions. `MyComp` is 1280×720 @ 30fps.
  - `src/Composition.tsx` — the actual video. Currently empty.
  - `remotion.config.ts`, `eslint.config.mjs`, `tsconfig.json`, `.prettierrc` — config.
- `text.txt`, `text 2.txt`, `text 3.txt` — RHYTHMIX landing-page HTML/CSS. Source of truth for copy, brand colors, pricing, testimonials. Read these before writing video content.
- `.claude/skills/remotion/` — domain skill with per-topic rule files (animations, captions, ffmpeg, fonts, etc.). Consult when touching Remotion APIs.
- `graphify-out/` — generated knowledge graph. Don't edit by hand.

## Stack

- Remotion 4.0.454, React 19.2, TypeScript 5.9
- Tailwind v4 via `@remotion/tailwind-v4`
- ESLint flat config (`eslint.config.mjs`), Prettier

## Commands (run from `video/`)

- `npm run dev` — start Remotion Studio for preview
- `npm run build` — bundle
- `npm run lint` — ESLint + `tsc` (use this to verify before declaring done)
- `npx remotion still MyComp --scale=0.25 --frame=30` — single-frame sanity render

## Conventions

- TypeScript strict; no `any` unless justified.
- Components are function components with explicit `React.FC` only when children typing actually matters.
- Tailwind classes preferred over inline styles for static layout; use `style={}` for animated/interpolated values.
- Frame-based timing (Remotion). Use `useCurrentFrame()` and `interpolate()` rather than CSS transitions.
- Keep `Composition` props pure-serializable (no functions, no Date instances) so Studio can hot-reload.

## Brand (from `text*.txt`)

- Product: RHYTHMIX, AI music creation platform
- Competitors referenced: Suno, Udio, LANDR
- Pricing: tiered + $149 lifetime
- Visual language: dark theme, red/purple gradients (`var(--red)`, `var(--purple)`), gold accents (`var(--gold)`)
