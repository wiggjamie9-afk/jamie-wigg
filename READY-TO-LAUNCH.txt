TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

If workflow fails, check:

1. Watercolor generation fails
   → Check: GitHub Secrets has REPLICATE_API_TOKEN
   → Fix: Try running workflow again

2. Narration fails
   → Check: GitHub Secrets has ELEVENLABS_API_KEY
   → Fallback: Uses Piper TTS (slower, free)

3. Video fails
   → Check: FFmpeg installed (automatic in workflow)
   → Check: Pages exist (run watercolor step first)

4. YouTube upload fails
   → Check: token.json is valid
   → Fix: Run: python kids-channel/youtube_auth.py
   → Update: YOUTUBE_* secrets in GitHub
