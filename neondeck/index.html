WHY // NEONDECK

Zero Dependencies

No React, no Tailwind, no npm install. Every template is a single HTML file plus one shared stylesheet — open it in a browser and it works.

Token-Driven Theming

Every color, glow, radius and font is a CSS custom property. Rebrand the entire kit by editing a dozen lines at the top of one file.

Charts Included

A 6 KB vanilla-JS SVG chart library — glowing line, area, donut, bars and sparklines — driven entirely by data attributes.

Responsive

Desktop-dense layouts that collapse cleanly to tablet and mobile. Sidebar becomes a top bar; grids stack; nothing overflows.

Motion, Considerately

Staggered load reveals, chart draw-ins and pulse states — all CSS/rAF, all disabled automatically under prefers-reduced-motion.

Commercial License

Use in unlimited client and personal projects. The only thing you can't do is resell the kit itself. Plain-English license included.
