## Description (paste into Gumroad)

**Stop fighting frameworks to get the neon look.**

NEONDECK is a hand-tuned, neon-noir dashboard UI kit built in pure HTML and
CSS. No React. No Tailwind. No npm install. Open any template in your
browser and it just works.

**What's inside**

- ⚡ **4 complete templates** — AI Analytics command center, Fintech trading
  desk, AI Agent fleet monitor, and a split sign-in page
- 🎨 **Token-driven design system** — every color, glow, radius and font is a
  CSS variable. Rebrand the entire kit by editing ~12 lines
- 📈 **Charts included** — a 6 KB dependency-free SVG chart library: glowing
  line/area charts, donuts, bars and sparklines, driven by data attributes
- 📱 **Responsive** — dense desktop layouts that collapse cleanly to mobile
- 🌀 **Motion, considerately** — staggered load reveals and chart draw-ins,
  automatically disabled for users who prefer reduced motion
- 🔌 **Backend included** — a zero-dependency Node.js server (one file, no
  npm install) that feeds every dashboard live data from editable JSON files
  and powers a real login flow on the sign-in page (`node server/server.js`
  and you're running full-stack)

- 📄 **Buyer README + plain-English commercial license**

**Who it's for**

Developers and freelancers who need a striking dark dashboard *today* —
for a SaaS MVP, a client demo, an internal tool, or a portfolio piece —
without adopting a component framework to get it.

**License**

Use in unlimited personal and client projects. The only thing you can't do
is resell the kit itself.

**Files**: instant download, ~60 KB ZIP. Works offline (the only external
request is Google Fonts, with instructions to self-host them included).
