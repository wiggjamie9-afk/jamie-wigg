TROUBLESHOOTING REFERENCE
=========================

If environment check fails:
  -> Read: ANDROID_BUILD_SETUP.md (sections on Android SDK installation)
  -> Run: bash SETUP-ANDROID-SDK.sh

If build fails:
  -> Check: BUILD_LOG.txt
  -> Run: ./verify-android-env.sh (re-verify environment)
  -> Try: ./build-apks.sh --only app-name (single app for debugging)

If APK not found after build:
  -> Check: builds/.tmp/<app-name>/android/app/build/outputs/apk/release/
  -> Look for: app-release-unsigned.apk or app-release.apk

If signing fails:
  -> Verify: keytool -list -v -keystore rhythmix.jks
  -> Retry: ./build-apks.sh (will regenerate keystore if corrupted)
