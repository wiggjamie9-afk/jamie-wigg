## Biggest Mistakes (Don't Do These)

❌ Publishing inconsistently (2 videos one week, 0 the next)
❌ Not capturing emails (just hoping people find you)
❌ Being too perfectionist (spending 5 hours editing 1 video)
❌ Vague CTAs (don't say "subscribe"; say "enroll for $99")
❌ Ignoring comments (reply to every comment in first 24 hours)
❌ Underpricing ($19 course signals low value)
❌ No landing page (link directly to YouTube; lose email captures)

## Commands to Remember

**Record video:**
```bash
1. Open OBS
2. Select scene: "Main Screen"
3. Hit "Start Recording"
4. Code + talk for 5-15 min
5. Hit "Stop Recording"
```

**Edit video:**
```bash
1. Open DaVinci Resolve
2. Import MP4
3. Trim silent sections (delete >2 sec pauses)
4. Add color correction (Whites +5, Blacks -5)
5. Add intro/outro (3-5 sec slides)
6. Export as YouTube preset
```

**Upload:**
```bash
1. YouTube.com/studio
2. Click "Upload videos"
3. Upload MP4
4. Fill title, description, thumbnail
5. Add tags (Agent Builder, Next.js, SaaS, etc)
6. Publish or schedule
```
