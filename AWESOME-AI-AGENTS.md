## Recommended Starting Path

Given the RHYTHMIX + HyperFrames + Claude Code stack in this repo, these five are the highest-leverage starting points:

1. **Building Effective Agents (Anthropic)** — Direct match for the Claude Code workflow already in use here.
2. **Claude Code Best Agentic Coding Practices** — Concrete tactics for the harness this repo runs on.
3. **Building Agents with MCP** — Aligns with the MCP servers already wired in `.mcp.json` (creative-stack, higgsfield, pollinations, github).
4. **MCP with Anthropic (course)** — Deeper foundations for authoring custom MCP servers, useful if extending `.claude/mcp/creative-stack/`.
5. **OpenAI Practical Guide to Building Agents** — Cross-vendor perspective for agent architecture decisions.
