## Strategy & Market

### 1. Market Breakdown System
```
Analyze the market for [YOUR NICHE].

Do NOT give surface insights.

→ Break into: TAM, SAM, SOM
→ Identify top 5 trends shaping demand
→ Find 5 underserved opportunities
→ Highlight where money is already flowing

Output as structured insights, not paragraphs.
```

### 2. Problem Prioritization Engine
```
List the top 10 problems in [INDUSTRY]

→ Rank by urgency (1–10)
→ Rank by willingness to pay
→ Identify which problems are growing fastest
→ Highlight problems people actively complain about

Output as a ranked table.
```

### 3. Competitor Weakness Map
```
Analyze top 5 competitors in [NICHE]

→ What they do best
→ Where they are weak
→ What audience they ignore
→ What positioning gap exists

Suggest how I can dominate this space.
```

### 4. Design Blueprint
```
Design a [TYPE OF ASSET] for [YOUR BRAND/PRODUCT].

Deliver four sections:

1. Creative direction: define the aesthetic using three clear adjectives and include one reference style (e.g. brutalist editorial, minimal SaaS, luxury dark). Briefly explain the intent behind the direction.

2. Color system: provide primary, secondary, and accent colors with hex codes, along with a short rationale for how each color supports hierarchy and brand perception.

3. Typography: choose a headline and body font pairing, and define basic usage rules including hierarchy, spacing, and contrast.

4. Layout principles: describe the grid structure, spacing logic, and overall visual hierarchy, and include one rule that should never be broken.

Format each section with a bold heading and concise bullet points. Keep it under 400 words.
```

### 5. Design Teardown
```
Analyze the visual identity of the top 5 competitors in [YOUR NICHE].

For each competitor, include:
- What their design signals to the audience (premium, playful, technical, etc.)
- Their color and typography choices
- What works well visually
- What their design fails to communicate

Then:
- Identify 2–3 visual gaps that no competitor currently owns
- Highlight common patterns or overused styles across the market
- Recommend one clear visual direction for a new entrant

Output competitors in a table, followed by a short synthesis and final recommendation.
```

## Offer & Positioning

### 6. Offer Creation Framework
```
Create a high-converting offer for: [PROBLEM]

→ Define ICP (ideal customer profile)
→ Craft a clear value proposition
→ Add pricing strategy (low, mid, premium tiers)
→ Include guarantee + risk reversal
→ Show why this beats competitors

Output like a landing page structure.
```

### 7. Landing Page Builder
```
Create a high-converting landing page for [YOUR OFFER], targeting [ICP].

Structure it in this order:
1. Hero: headline, subheadline, and CTA
2. Problem: three pain points the audience is currently facing
3. Solution: the core transformation explained simply
4. Social proof: the type of validation that would be most effective, with examples
5. Offer: deliverables, format, and what's included
6. Pricing + guarantee: pricing structure and risk-reversal
7. Final CTA: a closing section designed to drive action

Write it as real page copy. No filler or generic phrasing.
```

### 8. Brand Voice
```
Define a brand voice system for [YOUR BRAND].

Structure it as a usable style guide:
1. Voice in 3 words: the core personality traits
2. Tone by context: how the voice adapts across ads, emails, social, and support
3. Vocabulary rules: 5 words/phrases to consistently use, 5 to avoid
4. Headline framework: the structural pattern that fits this brand
5. Example rewrites: take 3 generic lines and rewrite them in this voice: [PASTE LINES]

Output each section with a bold header. Make it specific enough that a new writer can apply it immediately.
```

### 9. Pitch Deck
```
Build the narrative for an 8-slide pitch deck for [YOUR STARTUP/IDEA].

Include:
1. Problem: one clear statement + who it affects
2. Market: TAM/SAM/SOM with assumptions
3. Solution: the core mechanism, not a feature list
4. Why now: the shift that makes this possible
5. Business model: how revenue flows
6. Traction: the strongest proof point
7. Team: why this team is uniquely suited
8. Ask: funding amount and what it unlocks

Each slide should include one headline and up to three bullets. Keep it concise and specific.
```

## Scaling

### 12. Scale System (short)
```
Give me a plan to scale this to [TARGET REVENUE]/month: [DESCRIBE BUSINESS]

→ What to automate first
→ What to delegate
→ What systems to build
→ Hiring roadmap
→ Bottlenecks that will appear

Output as execution roadmap.
```

### 13. Scaling System (4-phase, design-focused)
```
Give me a design production plan to scale visual output for [YOUR BUSINESS] to [TARGET VOLUME] per week within [TIMEFRAME].

Business context: [what you create, who it's for, current output, team size, biggest bottleneck]

Structure it in four phases:
1. Phase 1: Systemize (Week 1–2): what to template and document before scaling
2. Phase 2: Automate (Week 3–4): top 3 design tasks to automate, with tool suggestions
3. Phase 3: Delegate (Month 2): what to hand off first, in order, with rough cost
4. Phase 4: Scale (Month 3+): the leverage point that increases output without proportional effort

Also include:
- Main bottleneck at each phase transition
- One key metric to track per phase (not vanity)

Output as a structured roadmap with clear phase headers.
```
