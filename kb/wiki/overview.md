# Overview

The evolving synthesis of everything in this knowledge base — what the sources add up to,
where the open questions are, and how the picture has changed over time.

So far the wiki holds only its founding document, the
[llm-wiki pattern](sources/llm-wiki-pattern.md): knowledge should be compiled once at ingest
and kept current, not re-derived per query. This page will become the real synthesis once
domain sources start arriving in `kb/raw/`.

**Open question:** what domain will this knowledge base track first? The pattern supports
research, reading companions, business intelligence, personal tracking — the structure here
is domain-neutral until the first real source decides it.
