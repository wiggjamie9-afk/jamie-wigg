TROUBLESHOOTING
================================================================================

Q: "REPLICATE_API_TOKEN not set"
A: Set token in .claude/settings.local.json before running generate-keyframes.mjs

Q: "Prediction polling timeout"
A: Check Replicate API status (replicate.com/status). Try again after 5 min.

Q: Image doesn't match brief (e.g., wrong color, too photorealistic)
A: Edit prompt in generate-keyframes.mjs, regenerate single frame, replace PNG

Q: Can't download image (network error)
A: Check internet connection. Replicate URLs are temporary (~1 hour).

Q: Node.js version mismatch
A: Ensure Node 18+. Install from https://nodejs.org/
