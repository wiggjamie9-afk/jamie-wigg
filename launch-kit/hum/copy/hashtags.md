## 7. Brand-owned tags (own from day one)

Three tags HUM should claim and use consistently across every platform. Suggested spellings, capitalisation conventions, and rationale.

| Tag | Use everywhere | Notes |
|-----|----------------|-------|
| **`#humthepractice`** | All platforms, all posts | The flagship. Echoes the splash copy ("A practice."). Long enough to be unique, short enough to type. |
| **`#humapp`** | All platforms, demo / how-to posts | Generic enough to capture organic search, owned-enough to claim. |
| **`#thequietprogram`** | Tinnitus-program posts only | Program-specific so each of the four programs eventually owns a tag. (Plan to add `#thedescentprogram`, `#thetoneprogram`, `#theclearingprogram` as those launches happen.) |

Capitalisation: lowercase by default on Instagram and TikTok; CamelCase (`#HumThePractice`) on Twitter/X and LinkedIn for legibility. Same tag, two renderings — both count as the same hashtag.

Reservation: register the spellings as Instagram, TikTok, and X *account handles* if any are still available — `@humthepractice` and `@hum.app` are the priority order.
