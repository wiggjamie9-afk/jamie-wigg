# Publish Sonny's Cozy Quokka Bedtime Tales on Amazon — Simple Checklist

You have 35 books ready. Each one goes up on Amazon **two ways**: a **Kindle
eBook** (people read it on their phone/Kindle) and a **Paperback** (Amazon
prints a real book and posts it). Do both for every book — more ways to sell.

Everything you need for each book is in its own folder / zip, e.g.
`book01-sunny-and-the-flying-fox`. Open the `05-LISTING.txt` in that folder —
it has the exact Title, Description, keywords and price to copy and paste.

Go to **kdp.amazon.com** and sign in. Then work down the list of 35 books.

---

## ONE-TIME SETUP (first visit only)
- [ ] Create your KDP account at kdp.amazon.com (free).
- [ ] Fill in your **tax details** and **bank details** (so Amazon can pay you).
      You can't publish until this is done once. It carries over to every book.

---

## FOR EACH BOOK — KINDLE eBOOK (do this first, it's quicker)

1. [ ] KDP dashboard → **Create** → **Kindle eBook**.
2. [ ] Open `05-LISTING.txt`. Copy the **Title** and **Subtitle** in.
3. [ ] Copy the **Description** in.
4. [ ] **Author:** Jamie Wigg.  **Language:** English.
5. [ ] Add the **7 keywords** from `05-LISTING.txt`.
6. [ ] Pick the **categories** from `05-LISTING.txt`.
7. [ ] Age range: **1 to 5**.
8. [ ] **Upload eBook file:** `04-KINDLE-ebook.epub`
9. [ ] **Upload cover:** `01-COVER-ebook.jpg`
10. [ ] Click through, set the **price** from `05-LISTING.txt`.
11. [ ] **Publish.**  (Amazon reviews it — usually live within 72 hours.)

## FOR EACH BOOK — PAPERBACK (same info, printed version)

1. [ ] KDP dashboard → **Create** → **Paperback**.
2. [ ] Paste the **same** Title / Subtitle / Description / keywords from `05-LISTING.txt`.
3. [ ] Print options — set these exactly:
       - Trim size: **11 x 8.5 in (landscape)**
       - Interior: **Premium colour**, **white** paper
       - Bleed: **No bleed**
       - Cover finish: **Glossy**
4. [ ] **Upload interior:** `03-INTERIOR-paperback.pdf`
5. [ ] **Cover:** choose **KDP Cover Creator**, upload `02-COVER-print.jpg`
       as the front cover image (Cover Creator builds the back + spine for you).
6. [ ] Click **Preview** — check every page looks right.
7. [ ] Set the **price**.  **Publish.**

## GOOD TO KNOW
- **You don't have to do all 35 at once.** Do a few a day — each one stays live once published.
- **AI-content note:** when KDP asks "Did you use AI?", answer **Yes** and tick
  images + text. That's already noted in each `05-LISTING.txt`. It's allowed —
  you just have to declare it.
- **Free ISBN:** let Amazon give you a free ISBN for the paperback (default option).
- **Changes later:** you can edit price, description or re-upload files anytime.
- **When people buy:** Kindle readers get the flipping-page storybook in their
  Kindle app; paperback buyers get a real printed book posted to them. You do nothing —
  Amazon handles delivery and printing, and pays you royalties.
