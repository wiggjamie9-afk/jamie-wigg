HOW TO PUT "Sunny and the Cassowary Chick" ON AMAZON
=====================================================

You can sell this book on Amazon TWO ways — a Kindle eBook and a printed
Paperback. Do both for the widest reach. Every file you need is listed below
with its exact location in your project.

THE FILES FOR THIS BOOK
  Cover (eBook + front) . kdp-covers/book35-kdp-cover.jpg
  Cover art (print) ..... kids-channel/portrait-covers/book35.png
  Paperback interior .... kdp-paperbacks/book35-sunny-and-the-cassowary-chick-paperback.pdf
  Kindle book (page-flip) book35/redesign/sunny-and-the-cassowary-chick.epub
  Listing text .......... amazon-products/book35-sunny-and-the-cassowary-chick/05-LISTING.txt

--------------------------------------------------------------------
KINDLE eBOOK  (quickest — do this first)
--------------------------------------------------------------------
 1. kdp.amazon.com  ->  Create  ->  Kindle eBook
 2. Open 05-LISTING.txt; paste in Title, Subtitle, Description.
 3. Add the 7 keywords and pick the categories from 05-LISTING.txt.
 4. Age range: 1-5.  Language: English.
 5. eBook content:  upload the Kindle book  (book35/redesign/sunny-and-the-cassowary-chick.epub)
 6. Cover:  upload the eBook cover  (kdp-covers/book35-kdp-cover.jpg)
 7. Set the price from 05-LISTING.txt.  Save & Publish.

--------------------------------------------------------------------
PAPERBACK  (same info, print version)
--------------------------------------------------------------------
 1. kdp.amazon.com  ->  Create  ->  Paperback
 2. Paste the same Title / Description / keywords from 05-LISTING.txt.
 3. Print options:
        Trim size ..... 11 x 8.5 in (landscape)
        Interior ...... Premium colour, white paper
        Bleed ......... No bleed
        Cover finish .. Glossy
 4. Interior file:  upload the paperback interior  (kdp-paperbacks/book35-sunny-and-the-cassowary-chick-paperback.pdf)
 5. Cover:  KDP Cover Creator, front image = kids-channel/portrait-covers/book35.png
 6. Preview -> Approve -> Publish.

Repeat for the next book folder.
