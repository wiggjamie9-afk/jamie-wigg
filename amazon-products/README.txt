SONNY'S COZY QUOKKA BEDTIME TALES — Amazon Product Bundles
===========================================================

One folder per book (35 total). Each folder is a COMPLETE, self-contained
Amazon product — open a folder, and everything you need to publish that one
title is right there. No hunting across the repo.

WHAT'S IN EVERY BOOK FOLDER
  01-COVER-ebook.jpg .......... cover, 1600 x 2560 (Kindle + paperback front)
  02-COVER-print.png .......... print-resolution cover art
  03-INTERIOR-paperback.pdf ... 11 x 8.5" landscape, 300 DPI, 17 illustrated pages
  04-KINDLE-ebook.epub ........ fixed-layout page-flip Kindle book
  05-LISTING.txt .............. title, subtitle, description, 7 keywords,
                                categories, age range, price — copy & paste
  HOW-TO-UPLOAD.txt ........... step-by-step for that exact book

HOW TO USE
  1. Pick a book folder (start with book01).
  2. Open HOW-TO-UPLOAD.txt and follow it.
  3. Each title goes up TWICE on Amazon: Kindle eBook (the .epub) and
     Paperback (the .pdf) — same cover, same listing text.
  4. Repeat for the next folder.
