## Character Overview

**Name:** ZIGGY  
**Role:** Energetic middle-school ADHD superhero protagonist  
**Key Traits:** Hopeful, brilliant, always in motion  
**Primary Colors:** Vibrant Orange (#FF8C00) & Electric Blue (#00D8FF)  
**Art Style:** Professional 2D cartoon (Vectteezy / modern animation studios)  
**Target Format:** 1920×1080 character design sheet with multiple poses and expressions

---

## Character Sheet Components

The generated artwork should include:

### Center Panel (Largest)
Full-body standing shot with arms raised, confident smile, showing energy and warmth

### Top Row - Head Variations (3 angles)
1. Front facing — direct, confident gaze
2. 3/4 Left turn — dynamic angle showing hair movement
3. 3/4 Right turn — balanced composition

### Right Column - Emotional Expressions (4 variations)
1. Happy/Excited — wide smile, bright eyes
2. Focused/Determined — concentration, intensity
3. Nervous/Anxious — concern, vulnerability
4. Powerful/Confident — strength, heroism

### Bottom Row - Action Poses (4 variations)
1. Running forward — dynamic stride, energy
2. Jumping — mid-air joy, freedom
3. Thinking pose — thoughtful, contemplative
4. Celebrating — victory, triumph

## Visual Identity

### Costume
- **Vibrant Orange Hoodie (#FF8C00):** Primary focal point, comfortable fit
- **Electric Blue Trim (#00D8FF):** Cuffs, zipper, pockets, hood edges
- **Peachy Skin Tone (#F4A570):** Warm, relatable
- **Dark Spiky Hair (#2C2416):** Short, windswept, with shine/movement
- **Bright Eyes (#8B6F47):** Big, expressive, with animated highlights

### Art Style Requirements
- Professional 2D cartoon (Vectteezy / animation studio aesthetic)
- Clean, bold outlines (cel-shading friendly)
- Vibrant, saturated flat colors — NO gradients or shadows
- Pure white background
- High-resolution studio quality (1920×1080)

## Generation Options

### Replicate FLUX 1.1 Pro (Recommended)
- **Quality:** Professional, excellent prompt adherence
- **Cost:** ~$0.15 USD per generation
- **Speed:** 30-60 seconds
- **Setup:** Requires API token at https://replicate.com

### Midjourney
- **Quality:** Excellent, very reliable
- **Cost:** ~0.25 credits per generation (with subscription)
- **Platform:** Discord
- **Command:** `/imagine [prompt] --ar 16:9 --q 1 --s 750`

### DALL-E 3 via OpenAI
- **Quality:** Good, reliable
- **Cost:** $0.08 per generation
- **Setup:** Requires OpenAI API key

### Pollinations (Free)
- **Quality:** Good
- **Cost:** Free
- **Speed:** 20-40 seconds
- **Limitation:** Rate-limited but no authentication required

Professional 2D cartoon character design sheet in the style of Vectteezy and modern animation studios. Ziggy, energetic middle-school ADHD superhero protagonist. Center (largest): Full-body character standing confidently, friendly smile, arms raised with energy. Top row: 3 head variations - front facing, 3/4 left turn, 3/4 right turn. Character design: Warm peachy skin tone, short dark spiky hair with shine/movement, big bright eyes with highlights. Posture shows constant barely-contained energy - always in motion, hopeful, brilliant. Color palette: Orange, Electric Blue, Warm skin tones, bright happy colors. High quality studio illustration.
