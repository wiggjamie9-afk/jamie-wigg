The 16:9 character design sheet includes:

- **3 Head Variations** (Front, 3/4 Left, 3/4 Right)
- **4 Facial Expressions** (Happy/Excited, Focused/Determined, Nervous/Anxious, Powerful/Confident)
- **1 Full-Body Main Pose** (Barely-contained energetic motion)
- **4 Action Poses** (Running, Jumping, Thinking, Celebrating)

## How to Generate the Image

### Prerequisites
- Access to FLUX 1.1 Pro (via Replicate API, Anthropic, or similar service)
- REPLICATE_API_TOKEN configured (if using Replicate)

### Steps

1. **Open ZIGGY-GENERATION-PROMPT.txt**
2. **Copy the MAIN PROMPT section** (the large paragraph)
3. **Go to your image generation interface** (Replicate, Anthropic Claude, etc.)
4. **Set parameters:**
   - Model: FLUX 1.1 Pro
   - Aspect Ratio: 16:9
   - Format: PNG
   - Quality: High/Maximum
5. **Paste the prompt** into the generation interface
6. **Click Generate** (will take 1-2 minutes)
7. **Download and save as:** `ZIGGY-character-design-sheet.png`
8. **Review against the quality checklist** in ZIGGY-CHARACTER-BRIEF.md

### Estimated Cost
~$0.50-1.00 USD (depending on FLUX 1.1 Pro pricing)
