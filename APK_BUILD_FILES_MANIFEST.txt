  Usage: ./build-apks.sh [OPTIONS]
  Options:
    --dry-run       Validate without building (<5 seconds)
    --skip-signing  Build without signing (faster for testing)
    --only app-name Build single app only
  
  Process:
    1. Initializes Capacitor project per app
    2. Copies HTML/CSS/JS to web root
    3. Generates capacitor.config.json with package name
    4. Installs dependencies (npm)
    5. Adds Android platform (npx cap add android)
    6. Syncs web assets (npx cap sync)
    7. Builds release APK (npx cap build android --release)
    8. Signs with rhythmix.jks keystore
    9. Outputs to builds/*.apk
