# HerdCheck Mobile

Capacitor 7 wrapper for the HerdCheck livestock screening PWA. Packages the web app for Android (Google Play). iOS support planned for v1.1.

## Quick Start

```bash
# Install dependencies
npm install

# Sync web assets from livestock/ to native projects
npx cap sync

# Open in Android Studio
npx cap open android

# Run PR tests
npm run test 2>/dev/null || npx cap doctor
```

## Key Files

### `capacitor.config.ts`
- Configures app name, bundle ID, web directory
- Points to `../livestock/` as web source
- Defines iOS + Android signing options
- Registers Camera and Geolocation plugins

### `codemagic.yaml`
Two workflows:

1. **android-release**: Tag push (v*.*.* ) → build Android .aab → upload Play Console Internal
2. **test-pr**: PR creation → run Capacitor doctor checks

### `src/license-validator.ts`
- Validates Gumroad license keys via STARLIGHTMIX Studio API
- Stores validation result in localStorage (offline support)
- Called by livestock/ web app on load

## Development

### Add a Plugin

Example: Adding File Storage plugin:

```bash

```

### Test on Device

Android:

## CI/CD

Codemagic automatically:
1. Detects tag push (v0.1.0, v1.0.0, etc.)
2. Builds Android .aab
3. Uploads to Play Console Internal Testing

To trigger:
```bash
git tag v0.0.1
git push origin v0.0.1
# Watch Codemagic build at https://codemagic.io
```
