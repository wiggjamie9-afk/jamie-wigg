# HerdCheck Mobile

Capacitor 7 wrapper for the HerdCheck livestock screening PWA. Packages the web app for iOS (App Store) and Android (Google Play).

## Quick Start

```bash
# Install dependencies
npm install

# Sync web assets from livestock/ to native projects
npx cap sync

# Open in Xcode (iOS)
npx cap open ios

# Open in Android Studio (Android)
npx cap open android

# Run PR tests
npm run test 2>/dev/null || npx cap doctor
```

## Key Files

### `capacitor.config.ts`
- Configures app name, bundle ID, web directory
- Points to `../livestock/` as web source
- Defines iOS + Android signing options
- Registers Camera and Geolocation plugins

### `codemagic.yaml`
Three workflows:

1. **ios-testflight**: Tag push (v*.*.* ) → build iOS .ipa → upload TestFlight
2. **android-release**: Tag push (v*.*.* ) → build Android .aab + APK → upload Play Console Internal
3. **test-pr**: PR creation → run flutter analyze + doctor

### `src/license-validator.ts`
- Validates Gumroad license keys via STARLIGHTMIX Studio API
- Stores validation result in localStorage (offline support)
- Called by livestock/ web app on load

## Development

### Add a Plugin

Example: Adding File Storage plugin:

```bash
npm install @capacitor/filesystem
npx cap sync
```

### Test on Device

iOS (requires Mac + Xcode):
```bash
npx cap open ios
# In Xcode: select a device, Product → Run (Cmd+R)
```

Android:
```bash
npx cap open android
# In Android Studio: select a device, Run App (Shift+F10)
```

## CI/CD

Codemagic automatically:
1. Detects tag push (v0.1.0, v1.0.0, etc.)
2. Builds iOS .ipa + Android .aab
3. Uploads to TestFlight (iOS) + Play Console Internal (Android)

To trigger:
```bash
git tag v0.0.1
git push origin v0.0.1
# Watch Codemagic build at https://codemagic.io
```
