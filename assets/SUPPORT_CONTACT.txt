FAQs & Self-Help Resources
=====================================

COMMON ISSUES & SOLUTIONS:

Q: App won't install / "Download failed"
A:
  - Clear Google Play/App Store cache
  - Free up device storage (at least 100 MB required)
  - Try WiFi instead of mobile data
  - Log out and back into app store account
  - Restart device
  Contact support if issue persists.

Q: "Permission denied" for camera/microphone
A:
  - Go to Device Settings > [App Name] > Permissions
  - Toggle camera/microphone ON
  - If still denied, uninstall + reinstall app
  - Grant permission when prompted on first launch
  Note: Some apps work without permissions (camera is optional for many)

Q: App crashes on launch
A:
  - Uninstall the app completely
  - Restart device
  - Reinstall from app store (check for updates first)
  - Clear app cache: Settings > Apps > [App Name] > Storage > Clear Cache
  Contact support if crash persists with error message.

Q: Data lost after reinstalling
A:
  - All local data is stored in app cache (uninstall deletes it)
  - If you enabled cloud backup, your data is safe (sign back in to restore)
  - If no backup was enabled, unrecoverable data loss may occur
  Recommendation: Enable cloud backup in app settings (if available)

Q: Subscription won't cancel
A:
  - In-app cancellation: Settings > Subscriptions > [App Name] > Cancel
  - Alternatively: App Store (iOS) or Google Play (Android) > Subscriptions > [App Name] > Cancel
  - Do NOT uninstall app; cancellation must be done through app store
  Contact support if cancellation fails after 24 hours.

Q: Refund request
A:
  - Initiated through app store (Apple / Google), not directly through us
  - Response time: 5–10 business days from app store
  - We honor all legally required refunds; follow app store's refund policy
  Contact us if app store denies refund unfairly.

Q: Privacy / My data was deleted
A:
  - App data is stored locally on your device only (unless you enabled cloud backup)
  - Uninstalling the app or clearing cache deletes local data permanently
  - We cannot recover deleted local data
  - If cloud backup enabled, sign in with same account to restore
  Recommendation: Back up important data regularly (export CSV/PDF if available)

REPORTING A BUG
=====================================

To help us reproduce and fix your issue quickly, please provide:

1. Device Information
   - Device model (e.g., iPhone 15, Samsung Galaxy S24)
   - Operating system version (e.g., iOS 18.2, Android 14)
   - App version (visible in app settings)

2. Issue Details
   - Exact error message (screenshot or text)
   - When does it happen? (on launch, specific feature, random)
   - Steps to reproduce (numbered list)
   - How often? (every time, intermittent, first occurrence)

3. Evidence
   - Screenshot of error (if visual)
   - Video screencast (if complex interaction)
   - System logs (if available; optional)

4. Context
   - What were you trying to do?
   - What was expected vs. what happened?
   - Any recent changes to device (new app, iOS update, storage full)?

Example Bug Report:

Subject: BUG REPORT: FOCUS - Timer crashes on iPhone 15 Pro

Device: iPhone 15 Pro, iOS 18.2, FOCUS v2.3.1

Steps to reproduce:
1. Launch FOCUS app
2. Set timer to 25 minutes
3. Enable binaural 40 Hz waves
4. Press play button
5. After 5 seconds, app crashes with error

Error message: "Fatal Exception: Audio Engine Timeout"

Expected: Timer should run for 25 minutes with audio playing
Actual: App closes immediately

This happens every time. Tried uninstalling and reinstalling; issue persists.

SECURITY & RESPONSIBLE DISCLOSURE
=====================================

Found a security vulnerability?

1. Do NOT publicly disclose the vulnerability
2. Email: security@rhythmixapp.com.au with:
   - Description of vulnerability
   - Affected feature/component
   - Proof of concept (non-destructive)
   - Your suggested fix (if any)
3. We will:
   - Acknowledge receipt within 24 hours
   - Investigate and confirm the issue
   - Develop and test a fix
   - Release patch and credit researcher (unless you prefer anonymity)
   - Timeline: 30–90 days depending on severity

We appreciate responsible disclosure and welcome security researchers.
