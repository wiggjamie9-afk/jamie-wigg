DOCKET - Legal Document and Contract Manager

Value Proposition
Contract parser, deadline tracker, signature capture, and document archive. Offline-first security for legal professionals and contract-heavy businesses. One-time purchase.

Key Features
• Document Parser: Automatically extracts key dates, parties, terms from contracts
• Deadline Tracker: Renewal, termination, and review dates with alerts
• Signature Capture: Digital signature capture (legally recognised in many jurisdictions)
• Full-Text Search: Search contract terms across your entire document library
• Party Directory: Contacts for all contract parties (vendors, clients, partners)
• Status Tracking: Track negotiation status, signed, executed, archived
• Obligations Log: Extract and track key obligations per contract
• Offline Security: All documents stored locally; zero cloud access
• PDF Annotation: Highlight terms, add notes directly on document
• Export Binder: Create document package for legal review or negotiation

Who It's For
Lawyers, in-house counsel, contract managers, procurement professionals, and small business owners managing multiple contracts.

Pricing
One-time purchase (pricing TBD). No subscriptions.

Privacy Statement
DOCKET stores all contracts and metadata locally in IndexedDB. No documents are transmitted to cloud servers or shared with third parties. We do not analyse contract content for legal advice or predictive purposes. Complete privacy and local control.

Accessibility
• Large document upload button
• High-contrast dark theme
• Screen reader compatible contract list
• Haptic feedback on deadline alerts
• Adjustable font sizes for contract reading
• Simplified date entry

Technical Details
• PDF.js for contract parsing and display
• IndexedDB for document storage and metadata
• Full-text search using TF-IDF algorithm
• Signature capture via Canvas API
• Compatible with: iOS 12+, Android 8+
• Storage: ~200 MB for 100 contracts (avg. 2 MB per contract)

Installation & Usage
1. Visit rhythmixapp.com.au/apps/untapped/docket
2. Purchase one-time licence
3. Upload contract (PDF or image scan)
4. DOCKET auto-extracts: parties, dates, obligations
5. Set deadline alerts (renewal, termination, review)
6. Add parties to contact directory
7. Capture signatures when contract executed
8. Export contract package for negotiation or legal review

Features Breakdown
- Parser: Extracts dates, parties, key terms using regex and ML
- Deadline: Automatic alert 30, 7, 1 days before key dates
- Signature: Digital signature with timestamp and party details
- Search: Full-text search across all documents (fast local indexing)
- Annotations: Highlight and comment on contract text
- Archive: Move old contracts to archive view
