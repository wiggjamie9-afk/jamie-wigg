SPOT - Site Inspection and Defect Logger

Value Proposition
Photo-based site inspection tool with defect marking, timestamp logging, and PDF report generation. Perfect for builders, inspectors, and site managers. One-time purchase.

Key Features
• Photo-Based Logging: Take photos on-site; mark defects directly on images
• Defect Marking: Pin defects to exact locations on photos with annotations
• Timestamp Tracking: Auto-capture time, date, and optional location (GPS)
• Severity Levels: Critical, major, minor defect categorisation
• Area Tagging: Group defects by building area (foundation, walls, roof, electrical, plumbing)
• Checklist Templates: Pre-built inspection checklists (handover, pre-move, 6-month, 12-month)
• PDF Report: Generate professional inspection report with all photos and annotations
• Inspector Info: Sign report with name and credentials
• Offline Ready: Works on-site without internet
• Revision History: Track multiple inspections of same property over time

Who It's For
Builders, site inspectors, property managers, construction supervisors, structural engineers, and real estate professionals conducting site inspections.

Pricing
One-time purchase (pricing TBD). No subscriptions.

Privacy Statement
SPOT stores all inspection photos and defect data locally in IndexedDB. Optional GPS location is stored only if enabled by user. No data is transmitted to cloud servers or shared with third parties unless you explicitly export PDF reports. Complete confidentiality for builders and inspectors.

Accessibility
• Large photo capture button
• High-contrast dark theme

• Screen reader compatible checklist
• Haptic feedback on defect marking

Technical Details
• Geolocation API for optional GPS timestamp
• Canvas-based photo annotation
• IndexedDB for inspection logs
• PDF generation via jsPDF + html2canvas
• Compatible with: iOS 12+, Android 8+
• Storage: ~200 MB for 50 inspections with ~20 photos each

Installation & Usage
1. Visit rhythmixapp.com.au/apps/untapped/spot
2. Purchase one-time licence
3. Create new inspection (property address, inspector name, type)
4. Select checklist template or custom checklist
5. Take photo of each area needing inspection
6. Mark defects directly on photos (pin + annotation)
7. Assign severity and category to each defect
8. Generate PDF report with all findings
9. Sign report and export for client delivery

Inspection Types & Checklists
- Handover Inspection: Pre-handover defect list
- Final Inspection: Building completion checklist
- Pre-Move Inspection: Rental/purchase due diligence
- 6-Month Review: Post-construction settlement checks
- Maintenance Inspection: Routine property checks
- Damage Assessment: Post-incident or insurance claims

Defect Categories
- Foundation: Cracks, settling, water intrusion
- Structure: Walls, beams, columns, roof, framing
- Electrical: Wiring, outlets, switches, breaker issues
- Plumbing: Leaks, pressure, drainage, fixture issues
- Finishes: Drywall, flooring, paint, trim, doors, windows
- HVAC: Heating, cooling, ventilation system checks
- Safety: Handrails, stairs, egress, fire safety

Severity Levels
- Critical: Immediate safety risk or code violation (red)
- Major: Significant defect affecting function or durability (orange)
- Minor: Cosmetic or low-priority item (yellow)
- Note: Information or observation (blue)

Report Generation
- Title page: Property, date, inspector, signature
- Defect summary: Count by category and severity
- Photos with annotations: All marked defects
- Checklist results: Passed/failed items
- Recommendations: Prioritised repair list
- Footer: Inspector contact and date
