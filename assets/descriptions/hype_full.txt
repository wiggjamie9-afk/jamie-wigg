HYPE - AI Morning Affirmations and Voice Coaching

Value Proposition
AI-personalised morning affirmations based on your goals. Text-to-speech reads them aloud via Web Speech API for daily motivation. One-time $2.99.

Key Features
• Goal-Based Affirmations: Input 3–5 goals; AI generates personalised affirmations
• Daily Voice Reading: Text-to-speech narration of affirmations (your device's native voice)
• Tone Selection: Confident, gentle, energetic, or soft voice styles
• Streak Counter: Days of consecutive morning sessions
• Affirmation History: Log favorite affirmations to repeat later
• Quick Recall: Most-used affirmations pinned to home
• Meditation Timer: Optional 5-minute pause after affirmations (breathing guide)
• Offline Ready: All processing local; no API calls
• No Account: Nameless, anonymous affirmation practice
• Customise Frequency: Daily, weekday-only, or 3x/week

Who It's For
People seeking daily motivation, goal-setters, athletes preparing for competition, and anyone using affirmations for mindset training.

Pricing
One-time purchase $2.99. No subscriptions. No in-app purchases.

Privacy Statement
HYPE stores goals and affirmation preferences locally in IndexedDB. No personal data is transmitted to servers. Voice is generated via your device's built-in Web Speech API (no external TTS service). Goal statements are never shared or analysed by AI models; affirmations are generated client-side using templates. Zero tracking.
