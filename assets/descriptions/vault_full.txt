VAULT - Biometric-Locked Private Notes

Value Proposition
Biometric and PIN-locked private notes with zero cloud storage. WebAuthn, auto-lock, scrambled keypad, and complete privacy. One-time $4.99.

Key Features
• Biometric Lock: Fingerprint (iOS/Android) or face recognition unlock
• PIN Fallback: Numeric PIN (4–8 digits) if biometrics unavailable
• WebAuthn Support: Passwordless hardware key unlock (YubiKey, etc.)
• Scrambled Keypad: Numbers randomise each time to prevent pattern snooping
• Auto-Lock: Configurable lock timer (30 sec, 1 min, 5 min, immediate)
• Zero Cloud: All notes stored locally; no backup, no sync, no account
• Vanishing Notes: Optional note self-deletion after read (or set time)
• Note Encryption: AES-256 encryption on-device
• Offline First: Works completely without internet
• No Account: No email, no password, no identity tracking

Who It's For
Privacy-conscious individuals, security professionals, activists, journalists, and anyone storing sensitive personal or financial information.

Pricing
One-time purchase $4.99. No subscriptions. No cloud features.

Privacy Statement
VAULT stores all notes encrypted locally in IndexedDB using AES-256-GCM. We do not have access to encryption keys or note content. No data is transmitted to cloud servers. Biometric data (fingerprint, face) is processed entirely by your device's secure enclave; we never see it. Zero tracking, zero analytics, zero telemetry.

Accessibility
• Large, clear note entry area
• High-contrast dark theme
• Haptic feedback on biometric unlock
• Audio cue for successful unlock
• Screen reader compatible (with caution for privacy)

• Simplified PIN entry mode (no scramble option)

Technical Details
• WebCrypto API for AES-256-GCM encryption
• TouchID / FaceID via WebAuthn API
• IndexedDB for encrypted local storage
• Scramble algorithm: Fisher-Yates shuffle of 0–9 digits
• Compatible with: iOS 14+, Android 10+
• Storage: <1 MB per 100 notes (text only, lightweight)
• Encryption keys: Derived from biometric/PIN via PBKDF2

Installation
1. Visit rhythmixapp.com.au/apps/vault/
2. Purchase one-time $4.99
3. Set up biometric unlock (fingerprint or face)
4. Alternatively, set PIN (or both for redundancy)
5. Create first private note
6. Lock app (auto-lock timer starts)
7. Unlock with biometric or PIN to read notes

Supported Unlock Methods
- Fingerprint (iOS Secure Enclave, Android BiometricPrompt)
- Face Recognition (FaceID, Android Face Unlock)
- WebAuthn (YubiKey, Windows Hello, etc.)
- PIN (fallback, scrambled keypad)
- Multi-factor: Biometric + PIN for maximum security

Note Features
- Encrypt on-device (AES-256)
- Mark as "vanishing" (delete after read)
- Set self-destruct timer (5 min, 1 hour, custom)
- Search (full-text, encrypted)
- Tags (colour-coded, searchable)
- Edit history (optional versioning)
- No character limit (tested to 100k+ char)

Security Architecture
- Encryption keys never leave device
- Biometric unlock triggers decryption (secure enclave)
- PIN-derived key using PBKDF2 (100,000 iterations)
- Session encryption: New random key per session
- Memory wipe: Sensitive data cleared from RAM on lock

VAULT is a locally-encrypted note app, not a secure communication platform. For sensitive communications, use E2E-encrypted messaging apps (Signal, Wire).
