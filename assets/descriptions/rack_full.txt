RACK - Server and Network Asset Management

Value Proposition
Data center rack diagram tool, port inventory tracker, and cable management reference. Offline access for IT professionals and data centre managers. One-time purchase.

Key Features
• Rack Diagram: Visual representation of U-height rack with slotted devices
• Port Inventory: Ethernet, power, serial ports per device; track usage status
• Cable Management: Cable run tracker and cross-reference routing
• Device Database: Pre-loaded server, switch, patch panel models
• Custom Devices: Add custom hardware with port configurations
• Port Status: Available, occupied, reserved, failed—colour-coded view
• Search & Filter: Find devices or ports by name, type, or status
• Export Diagram: PDF export for documentation or vendor reference
• Offline Reference: Perfect for data centre floor visits (no connectivity)
• SVG Diagrams: Scale-friendly vector output

Who It's For
Data centre managers, network administrators, IT professionals, and system integrators managing complex infrastructure.

Pricing
One-time purchase (pricing TBD). No subscriptions.

Privacy Statement
RACK stores infrastructure diagrams and port data locally in IndexedDB. No sensitive network topology data is transmitted to cloud servers. Complete confidentiality for data centre professionals.

Installation & Usage
1. Visit rhythmixapp.com.au/apps/untapped/rack
2. Purchase one-time licence
3. Create new rack (U-height, type)
4. Add devices (servers, switches, patch panels)
5. Configure ports per device (Ethernet, power, serial)
6. Mark port status (available, occupied, reserved)
7. Track cable runs and cross-references
8. Export rack diagram as PDF for documentation

Rack Features
- Standard U-heights: 42U (full rack), 24U (half rack), custom
- Device placement: 1U, 2U, 4U, 8U heights
- Port types: Ethernet (10/100/1000, PoE), Power (IEC, C13), Serial, Fibre
- Status: Available, occupied, reserved, failed, testing
- Colour coding: Green (available), blue (occupied), yellow (reserved), red (failed)

Device Database
- Switches: Cisco, Juniper, Arista, HPE models
- Servers: Dell, HPE, Lenovo, custom builds
- Storage: SAN arrays, NAS, hard drives
- Networking: Patch panels, cable managers, PDU
- Custom: Add your own hardware models

Cable Management
- Cable type: CAT5e, CAT6, CAT6a, Fibre SM/MM, power
- Run tracking: Port-to-port cable routing (source, destination)
- Cross-reference: Which device pairs are cabled
- Export: Cable inventory for procurement or replacement

Disclaimer
RACK is a rack diagram and inventory tool, not a network monitoring system. For real-time port usage, link status, or bandwidth tracking, use dedicated network management tools (Nagibs, Zabbix, Prometheus). Physical cable runs should always be verified in-person; diagrams are reference only.
