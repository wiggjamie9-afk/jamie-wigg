LAPSE - Private Daily Photo Journal

Value Proposition
One photo per day. Private, no filters, no social. LAPSE stores your daily moments with calendar view, streak counter, and "on this day" memory lookback. One-time $2.99.

Key Features
• One Photo Daily: Encourage mindfulness through single-daily-photo discipline
• Calendar Grid: Visual timeline of the year—see daily photos at a glance
• Streak Counter: Consecutive days uploaded (reset or continue on miss)
• "On This Day": Automatic reminders of photos from previous years
• Private by Default: No sharing, no social feeds, no algorithm
• Photo Metadata: Auto-capture date, time, location (optional)
• Full-Year View: Scroll through 365 daily photos in grid mode
• Private Cloud: Optional encrypted backup (photos never shared)
• Export as Video: Optional slideshow creation (MP4)
• No Filters: Raw photo only—encourages authentic capture

Who It's For
Photography enthusiasts, journalers, mindfulness practitioners, and anyone seeking simple daily reflection without social comparison.

Pricing
One-time purchase $2.99. Optional $3.99/year encrypted cloud backup.

Privacy Statement
LAPSE stores all daily photos locally in IndexedDB (browser storage). No photos are transmitted to servers unless you explicitly enable cloud backup (encrypted end-to-end). No metadata is shared with social platforms. No tracking, no analytics beyond crash logs. Your photos remain completely private.

Accessibility
• Simple, large photo upload button
• High-contrast calendar grid
• Haptic feedback on daily capture
• Screen reader compatible date navigation
• Audio reminders for daily photo prompt
• Adjustable grid cell size
• Dark mode only

Technical Details
• IndexedDB for local photo storage and metadata
• Canvas-based calendar grid rendering
• Media Recorder API for optional slideshow video
• Compatible with: iOS 12+, Android 8+
• Storage: ~200 MB for 365 daily photos (500 KB/photo avg.)
• Optional backup: Encrypted to personal cloud via WebCrypto API
