SCAN - Receipt Scanner and Tax Filing Helper

Value Proposition
Photo a receipt, auto-categorise expenses, export CSV for tax filing. Built for Australian sole traders with tax-year grouping and quarterly GST estimates. One-time $4.99.

Key Features
• Receipt OCR: Photo-to-text extraction (date, vendor, amount, items)
• Auto-Categorise: Machine learning categorises receipts (meals, transport, supplies, equipment)
• Manual Categorise: Override categories for custom taxonomy
• Tax-Year Grouping: Australian FY (July–June) automatic grouping
• Quarterly GST: Calculates GST-inclusive and GST-exclusive totals by quarter
• CSV Export: Ready for MYOB, Xero, or accountant spreadsheet import
• Search & Filter: Find receipts by date, vendor, amount, category
• Receipt Archive: All photos stored locally (encrypted backup optional)
• Duplicate Detection: Alerts if same receipt scanned twice
• No Cloud: All processing happens on-device
• Offline First: Works without internet (cloud features optional)

Who It's For
Australian sole traders, freelancers, contractors, and small business owners managing tax deductions and GST compliance.

Pricing
One-time purchase $4.99. No subscriptions. Optional $9.99/year encrypted cloud backup.

Privacy Statement
SCAN stores all receipt photos, text extraction, and categorisation locally in IndexedDB. No data is transmitted to servers without explicit opt-in for encrypted backup. We do not track tax data, business revenue, or personal identity. All processing is client-side using Tesseract.js for OCR (open-source, no API calls).

Installation
1. Visit rhythmixapp.com.au/apps/scan/
2. Purchase one-time $4.99
3. Photo a receipt (or import from camera roll)
4. SCAN extracts date, vendor, amount automatically
5. Verify/edit if needed, assign category
6. Repeat for all receipts (batch processing available)
7. Export CSV for tax year (FY July–June)

Supported Receipt Categories (Australian)
- Meals & Entertainment: Restaurants, cafes, client lunches
- Transport: Fuel, parking, public transport, Uber
- Office Supplies: Stationery, printer ink, postage
- Equipment: Computer, furniture, tools (>$300 may require asset tracking)
- Software & Services: Adobe, web hosting, consulting fees
- Professional Development: Courses, books, conference attendance
- Other: Miscellaneous deductible expenses

GST Calculation
- Excluding GST (assume 10%): Amount ÷ 1.1
- Including GST: Amount as-is
- Quarterly totals: Automatic grouping by Australian tax quarter (Q1–Q4 FY)

Accountant Integration
- Export format: CSV compatible with MYOB, Xero, and manual spreadsheet
- Metadata included: Category, date, vendor, amount, notes
- Ready for: Accountant review, ATO substantiation, tax return preparation
