AXLE - Freelance Invoice and Project Manager

Value Proposition
Invoice generator, project timer, expense tracker, and client database for solo freelancers. All offline. Generates print-ready invoices and exports CSVs for accounting. One-time purchase.

Key Features
• Invoice Generator: Template-based invoices with your branding (logo, colours)
• Hourly Timer: Track billable hours per project with time-and-expenses summary
• Expense Logger: Record costs (materials, software, subcontractors)
• Client Database: Store contact info, rates, payment terms per client
• Project Templates: Save recurring project setups for faster invoicing
• CSV Export: Ready for accountant or bookkeeper
• Payment Tracking: Mark invoices paid/unpaid; track outstanding balance
• Offline First: All data stored locally; no cloud required
• Print-Ready: PDF invoices formatted for professional delivery
• Tax-Friendly: Optional AU/UK tax number fields for compliance

Who It's For
Freelancers, contractors, solo consultants, and small service providers managing multiple clients and invoicing cycles.

Pricing
One-time purchase (pricing TBD). No subscriptions.

Privacy Statement
AXLE stores all client data, invoices, and time logs locally in IndexedDB. No data is transmitted to cloud servers or shared with accounting platforms unless you explicitly export CSV. We do not track client info, project revenue, or payment status.

Accessibility
• Large buttons for timer start/stop
• High-contrast dark theme
• Screen reader compatible forms
• Haptic feedback on invoice generation
• Adjustable text sizes
• Simple language (no accounting jargon)

Technical Details
• HTML5 Canvas for PDF invoice rendering
• IndexedDB for client and project storage
• Timer using accurate system clock
• CSV export via Blob download
• Compatible with: iOS 12+, Android 8+
• Storage: ~5 MB for 100 clients + 500 time entries

Installation & Usage
1. Visit rhythmixapp.com.au/apps/untapped/axle
2. Purchase one-time licence
3. Add client (name, email, hourly rate, tax number)
4. Start project and timer for billable work
5. Log expenses (materials, subcontracting)
6. Generate invoice (pulls time entries + expenses)
7. Export PDF or print directly
8. Mark invoice as sent/paid

Invoice Details
- Client name and contact
- Invoice number and date
- Description of work/hours per project
- Hourly rate × hours = line item
- Expense summary (materials, subcontracting)
- Total before/after tax
- Payment terms and due date
- Payment method (bank transfer, PayPal, etc.)
